[[ref_template_awakend_requirements]]
== Voraussetzungen

Die Kreatur muss einen der folgenden primären Kreaturentypen besitzen:

* link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_animal.adoc[Tier]
* link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_construct.adoc[Konstrukt]
* link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_plant.adoc[Pflanze]

Die Kreatur muss außerdem den sekundären Kreaturentyp link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebend] besitzen.

[[ref_template_awakend_attributes]]
== Attribute

Die Kreatur erhält einen Bonus von +2 Stufen auf jedes ihrer Attribute xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_perception[Erkenntnis], xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_selfcontrol[Selbstbeherrschung] und xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_charisma[Charisma] unter der Voraussetzung das jeweilige Attribut hat eine Stufe von 2 oder weniger.

[[ref_template_awakend_talents]]
== Talente

Die Kreatur behält alle Talente ohne weitere Modifikation.

[[ref_template_awakend_skills]]
== Fähigkeiten

[[ref_template_awakend_skills_awakend]]
=== Erwacht
Die Kreatur erhält den sekundären Kreaturentyp link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_awakend.adoc[Erwacht].
Es gelten die dort vorgestellten Regeln.
