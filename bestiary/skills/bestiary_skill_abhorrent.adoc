Die Kreeatur hat eine widernatürliche Austrahlung. FÜr die Bestimmung von Zielen bei Effekten oder Zaubern, die über prmären oder sekundären Kreaturentype bestimmt werden, gelten neben den eigenen primären oder sekundären Typen der Kreaturen die parameteriesierten *Kreaturentypen*. Die Kreatur erhält dadurch keine neun Fähigkeiten oder Regeln basierend auf den Kreaturentypen.
Kreaurentypen, die eine Machtstufe besitzen (z.B. Drachen, Konstrukte oder Untote), werden als eine Machtstufe 1 gezählt.
