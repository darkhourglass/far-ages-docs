= Blindsinn (Reichweite)

*Voraussetzungen:* - +
*Typ:* Passiv, Sinn +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur hat einen außergewöhnlichen oder übernatürlichen Sinn der Wahrnehmung.
Innerhalb der angegebenen *Reichweite* kann die Kreatur immer jede andere Kreatur wahrnehmen.

Die Fähigkeit kann in unterschiedlichen Varianten dargestellt werden, zum Beispiel könnte die Kreatur die Erderschütterungen in seinem nahen Umfeld spüren oder einen besonders starken Geruchssinn haben.

Für direkte Angriffe muss weiterhin eine "Sichtlinie" vorhanden sein oder auch für Zauber oder Wasser, die Sichtweite erfordern, muss der freie Weg zum Ziel gegeben sein.
Auch wenn die Kreatur eine andere Kreatur beispielsweise hinter einer Wand spürt, kann sie diese nicht mit Pfeil und Bogen angreifen.

Die Kreatur ist innerhalb der Reichweite weiterhin immun gegen die negativen Effekte von sichtbasierten Einschränkungen wie zum Beispiel xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_darkness[Dunkelheit].
Dies inkludiert magische Effekte wie zum Beispiel die xref:../../compendiums/spells/spell_dust_cloud.adoc[Staubwolke].

Kreaturen außerhalb der Reichweite können nicht mit diesem Sinn erkannt werden.
