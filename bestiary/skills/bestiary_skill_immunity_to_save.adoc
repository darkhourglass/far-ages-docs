= Immun gegenüber Rettungswurf (Rettungswurf)

*Voraussetzungen:* - +
*Typ:* Passiv +
*CP:* tba +

Eine Kreatur mit dieser Eigenschaft besteht jede Probe für den angegebenen *Rettungswurf* automatisch.
Im Allgemeinen wird davon ausgegangen, dass die Kreatur von einem auslösenden Effekt für diesen Rettungswurf nie betroffen sein wird.

.Beispiel
====
link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_undead.adoc[Untote] besitzen diese Eigenschaft für diverse xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves[Rettungswürfe], zum Beispiel xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_check_saves_base_poisonresist[Gift].
Kommt ein Untoter mit einem xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons[Gift] in Kontakt, besteht er jeden Rettungswurf sofort und erleidet nie die Auswirkung eines Gifts.
====
