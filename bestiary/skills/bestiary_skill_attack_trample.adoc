= Zertreten (Angriffsstufe, Schaden)

Die Zertreten-Attakc erfolgt als Probe im xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_unarmed_combat[Unbewaffenten Kampf] mit der angegebenen *Angriffsstufe* oder mit dem gleichnamigen Talent der Kreatur.
Der Schadenswurf erfolgt mit dem angegebenen *Schaden*.

Gegen Kreaturen, deren xref:../../rules/core/core_rules_charactercreation.adoc#ref_characters_charactercreation_sizecategories[Größenkategorie] geringer ist, verursacht diese Attack mehr Schaden.
Die Kreatur erhält einen Bonuswürfel von 1W6 auf die xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_damagerolls[Schadenswürfel] pro Größenkategorie Unterschied.

.Zertreten
====
Eine Kreatur der GK 7 greift mit Zertreten eine Kreatur der GK 5 an.
Zwischen diesen Größenkategorien besteht ein Unterschied von 2.
Damit erhält die angreifende Kreatur einen zusätzlichen Bonus von 2W6 auf die Schadensprobe.
====
