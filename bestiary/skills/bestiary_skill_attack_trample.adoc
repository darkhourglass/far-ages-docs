= Zertreten (Angriffsstufe, Schaden, Anzahl)

*Voraussetzungen:* - +
*Typ:* Angriff, ST +
*Überanstrengung:* - +
*CP:* tba +

Die Zertreten-Attacke erfolgt als xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_basicrole[Probe] mit der angegebenen *Angriffsstufe*.
Diese enthält bereits alle Boni aus den Attributen und Talenten der Kreatur.
Der Schadenswurf erfolgt mit dem angegebenen *Schaden*.

Gegen Kreaturen, deren xref:../../rules/core/core_rules_charactercreation.adoc#ref_core_characters_charactercreation_sizecategories[Größenkategorie] geringer ist, verursacht diese Attack mehr Schaden.
Die Kreatur erhält einen Bonuswürfel von 1W6 auf die xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagerolls[Schadenswürfel] pro Größenkategorie Unterschied.

.Zertreten
====
Eine Kreatur der GK 7 greift mit Zertreten eine Kreatur der GK 5 an.
Zwischen diesen Größenkategorien besteht ein Unterschied von 2.
Damit erhält die angreifende Kreatur einen zusätzlichen Bonus von 2W6 auf die Schadensprobe.
====

Die angegebene *Anzahl* gibt an, wie oft die Kreatur im xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[eigenen Zug] diese Fähigkeit einsetzen kann.
Jeder einzelne Einsatz kostet eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion].
Ist die Anzahl nicht explizit angegeben, kann die Kreatur die Fähigkeit nur einmal pro eigenem Zug einsetzen.
