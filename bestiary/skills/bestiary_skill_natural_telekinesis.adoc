= Natürliche Telekinese (Reichweite)

*Voraussetzungen:* - +
*Typ:* - +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur besitzt eine natürliche, instinktive Fähigkeit zur Manipulation von Gegenständen mit der reinen Kraft ihrer Gedanken.
Sie kann innerhalb der angegebenen *Reichweite* Gegenstände einsetzen, manipulieren und bewegen, so als würde sie ihre Hände benutzen.
Die Kreatur kann mit der Telekinese nur solche Gegenstände einsetzen, die sie in Händen halten und führen könnte.
Hat die Kreatur keine Hände, wird angenommen, dass sie 2 Hände in der Größe angemessen für ihre xref:../../rules/core/core_rules_charactercreation.adoc#ref_core_characters_charactercreation_sizecategories[GK] besitzt.
Es können nur Gegenstände benutzt werden, die von der Kreatur wahrgenommen werden können.

Ist keine Reichweite angegeben, gilt eine ungefähre, natürliche Armlänge, jedoch nie mehr als 1,50 Meter.
