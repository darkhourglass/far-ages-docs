= Immun gegenüber Niederschlag

*Voraussetzungen:* - +
*Typ:* Passiv +
*CP:* tba +

Die Kreatur kann nicht xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_knockdown[niedergeschlagen] werden.
Proben, um einen Niederschlag zu widerstehen, gelten als automatisch bestanden.
Die Kreatur kann jedoch weiterhin xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds[Verletzungen] erhalten.
