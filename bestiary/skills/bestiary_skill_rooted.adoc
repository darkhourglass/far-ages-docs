= Verwurzelt

*Voraussetzungen:* - +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur ist unbeweglich, weil sie vielleicht wortwörtlich mit Wurzeln im Boden steckt oder weil sie auf andere Art am Boden befestigt ist.

Die Kreatur besitzt keine xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attributes_secondary_movementrate[BEW], unabhängig von ihrer xref:../../rules/core/core_rules_charactercreation.adoc#ref_core_characters_charactercreation_sizecategories[Größe].
Sie kann keine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktionen] verwenden, die den Einsatz einer BEW erfordern.

Die Kreatur gilt nicht als xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_condition_held[gefangen oder gehalten].
Sie ist immun gegenüber dem Zustand xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_condition_onground[am Boden] und kann nicht xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_knockdown[niedergeschlagen] werden.
