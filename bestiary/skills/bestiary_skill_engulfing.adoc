= Umschlingend

*Voraussetzungen:* Kreaturentyp +
*Typ:* Bewegung, Passiv +
*CP:* tba +

Die Kreatur kann aufgrund ihrer einzigartigen Physiologie sich um andere Kreaturen schlingen und vollständig umgeben.
Sie kann bei jedem Manöver, bei dem sie ihre xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attributes_secondary_movementrate[BEW] einsetzt, wie xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_maneuver_run[Rennen] oder xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_complexactions_sprint[Springen] sowie der Bewegung beim xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions_attack[Angriff], sich zum einen durch andere Kreaturen hindurchbewegen und zum anderen in einem Platz beenden, der durch eine andere Kreatur besetzt wird.
Sie kann dies jedoch nicht nutzen, um feste Hindernisse zu durchqueren.
Es gelten, so fern nicht anders angegeben, die normalen Regeln zur Provokation von xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_attacks_of_opportunity[Gelegenheitsangriffen].
