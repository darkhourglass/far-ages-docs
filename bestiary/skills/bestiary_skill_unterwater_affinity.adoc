= Unterwasser-Affinität

*Voraussetzungen:* link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebendig] +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* tba +

Eine Kreatur mit dieser Fähigkeit kann Unterwasser zu deutlich erweiterten Umfang atmen.
Es gelten die üblichen Regeln zum xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_drowing[Ertrinken], jedoch kann die Kreatur KO-viele Stunden unter Wasser bleiben bevor diese Regeln für sie greifen.

[NOTE]
Es gilt sonst ein Zeitraum von KO-vielen Kampfphasen.
