= Immun gegenüber Zustand (Zustand)

*Voraussetzungen:* - +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* tba +

Eine Kreatur mit dieser Fähigkeit ist gegenüber allen Auswirkung des angegebenen *Zustands* immun, siehe das entsprechende xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_conditions[Kapitel].
Kein Effekt kann diesen Zustand bei der Kreatur hervorrufen.
Ist ein xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves[Rettungswurf] nötig, um den Zustand abzuwehren, besteht die Kreatur diese Probe automatisch, unabhängig von allen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers[Modifikatoren] oder sonstigen Umständen.
