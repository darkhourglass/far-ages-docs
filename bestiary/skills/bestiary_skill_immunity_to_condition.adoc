= Immun gegenüber Zustand (Zustand)

*Voraussetzungen:* - +
*Typ:* Passiv +
*CP:* tba +

Eine Kreatur mit dieser Fähigkeit ist gegenüber allen Auswirkung des angegebenen *Zustands* immun, siehe das entsprechende xref:../../rules/core/core_rules_d10_system.adoc#ref_core_conditions[Kapitel].
Kein Effekt kann diesen Zustand bei der Kreatur hervorrufen.
Ist eine xref:../../rules/core/core_rules_d10_system.adoc#ref_core_saves[Probe] nötig, um den Zustand abzuwehren, besteht die Kreatur diese Probe automatisch, unabhängig von allen xref:../../rules/core/core_rules_d10_system.adoc#ref_core_situationalmodifiers[Modifikatoren] oder sonstigen Umständen.
