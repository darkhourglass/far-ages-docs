= Widerwärtig (Radius, Mindestwurf)

*Voraussetzungen:* - +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* 100 +
Das Aussehen der Kreatur oder auch ein ätzender Geruch oder eine andere übernatürliche Fähigkeit lässt anderen den Magen umdrehen.
Alle link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebende] Kreaturen im angegebenen *Radius* müssen zu Beginn ihres xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[eigenen Zugs] einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_fortitude[Körper-Rettungswurf] gegen den *Mindestwurf* ablegen.
Alle Kreaturen, die den Rettungswurf nicht bestehen, erhalten den Zustand xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_condition_nauseated[Übelkeit].
Kreaturen, die bei dem Rettungswurf einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_botches[Patzer] würfeln, erhalten außerdem eine Stufe xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_condition_dazed[Benommenheit].
