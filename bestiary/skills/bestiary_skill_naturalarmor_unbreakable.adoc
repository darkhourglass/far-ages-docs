= Unnachgiebige natürliche Rüstung (Rüstungspunkte)

*Voraussetzungen:* - +
*Typ:* Passiv, Rüstung +
*Überanstrengung:* - +
*CP:* tba +

Diese Kreatur besitzt besonders harte link:bestiary_skill_naturalarmor.adoc[natürliche Rüstung].
Zusätzlich zu den Regeln der link:bestiary_skill_naturalarmor.adoc[natürlichen Rüstung] besitzt diese die Eigenschaft xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_items_armor_tag_unbreakable[unnachgiebig].
Das bedeutet, dass die Kreatur immer den vollen Rüstungsschutz der angegebenen *Rüstungspunkte* erhält, auch wenn sie durch eine Waffe mit der Eigenschaft xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_items_weapons_tag_armorpiercing[rüstungsbrechend] Schaden erhält.
