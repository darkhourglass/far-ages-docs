= Flink

*Voraussetzungen:* - +
*Typ:* Bewegung +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur ist äußerst geschickt und beweglich.
Benutzt die Kreatur in ihrer Kampfphase eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_action_move[Bewegung], um sich durch xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_and_unarmed_zoneofcontroll[Bedrohungszonen] seiner Gegner zu bewegen, so verursacht er keine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_attacks_of_opportunity[Gelegenheitsangriffe].
