= Flink

*Voraussetzungen:* - +
*Typ:* Bewegungsmanöver +
*CP:* tba +

Die Kreatur ist äußerst geschickt und beweglich.
Benutzt die Kreatur in ihrer Kampfphase ein xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_maneuver[Manöver], um sich durch xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_and_unarmed_zoneofcontroll[Bedrohungszonen] seiner Gegner zu bewegen, so verursacht er keine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_attacks_of_opportunity[Gelegenheitsangriffe].
