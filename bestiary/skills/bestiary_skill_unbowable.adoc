= Unbeugsam

*Voraussetzungen:* - +
*Typ:* Übernatürlich, Passiv +
*Überanstrengung:* - +
*CP:* tba +
Die Kreatur kann moralisch nicht gebrochen werden.
Sie besitzt formal keine xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_sp[SP] (im Profil durch "-" angezeigt) und ist somit xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_conditions_immunity[Zustandsimmun] gegenüber Zuständen aus xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_conditions_and_thresholds[Schwellen] bzgl. des SP-Pools.
Sie ist grundsätzlich xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_conditions_immunity[Zustandsimmun] bei allen Zuständen der Kategorie "Verstand".
