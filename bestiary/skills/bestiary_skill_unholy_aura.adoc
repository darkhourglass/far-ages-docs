= Unheilige Aura (Radius)

*Voraussetzungen:* - +
*Typ:* Passiv, Aura, Übernatürlich +
*CP:* tba +

Die Kreatur strahlt eine dunkle, widernatürliche Macht aus.
Andere Kreaturen spüren dies instinktiv und weichen vor ihr zurück.

Die Unheilige Aura gilt zunächst immer auch als link:bestiary_skill_unnatural_aura.adoc[Übernatürliche Aura] der Stufe 4.
Das bedeutet, alle link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebenden] Kreaturen müssen in dem Moment, in dem sie in den *Radius* eintreten, eine xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_check_saves_base_willpower[Willenskraft-Probe] gegen 4 Erfolge ablegen.
Bei einem xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_failures[Misserfolg] erhalten sie einen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_hits_automatic_hit[automatischen Treffer] mit 1W6 xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetype_magical_aether[aetherisch] Schaden und sie müssen von der Kreatur xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_complexactions_retreat[fliehen].

Darüber hinaus erhalten alle link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebenden] Kreaturen einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_malus[Malus] von -5 auf alle Proben, die gegen die Kreatur gerichtet sind.
Dieser Malus gilt so lange sie sich im Radius der Aura aufhalten, unabhängig davon, ob sie die oben genannte Willenskraft-Probe bestanden haben oder nicht.
