= Mehrfach-Attacke (Attacke, Anzahl)

*Voraussetzungen:* Verwendete Fähigkeit mindestens auf Stufe 1 und die Fähigkeit wird als xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] verwendet +
*Typ:* Angriff, Verstärkung +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur darf die angegebene *Attacke* in seinem xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[eigenen Zug] als xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktion] einsetzen.
Die Bonus-Aktion zählt nicht gegen eine mögliche maximale Anzahl, die die Attacke eventuell besitzt.
Allerdings dürfen als xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions_general_limited_action_and_reaction[limitiert] gekennzeichnete Attacken mit der Bonus-Aktion nicht zweimal in der aktuellen Kampfphase verwendet werden.

Besitzt eine Kreatur diese Fähigkeiten mehrfach für unterschiedliche Attacken, dann muss sie auswählen, welchen Attacke sie für die Bonus-Aktion verwenden will.
