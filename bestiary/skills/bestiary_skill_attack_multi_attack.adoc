= Mehrfach-Attacke (Attacke, Anzahl)

*Voraussetzungen:* Verwendete Fähigkeit mindestens auf Stufe 1 und die Fähigkeit wird als xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] verwendet +
*Typ:* Angriff, Verstärkung +
*CP:* tba +

Mit dieser Fähigkeit kann eine Kreatur eine ihrer anderen *Attacken* innerhalb der eigenen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase[Kampfphase] mehrfach einsetzen und dies mit dem Einsatz einer einzigen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion].
Es muss sich dabei um eine offensive Fähigkeit oder Talent handeln, die die Kreatur zum xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_concurrentrolls_attackingroll[Angriffswurf] verwendet.

Die angegebene *Anzahl* gibt die Anzahl der Attacken an, die mit einem Mehrfach-Angriff ausgeführt werden.
Es muss sich dabei immer um die gleiche Fähigkeit oder Talent handeln, denn der Mehrfach-Angriff gilt immer nur für eine Fähigkeit.
Besitzt die Kreatur mehrere Fähigkeiten zum Angriff, können diese mit dieser Fähigkeit nicht gemischt eingesetzt werden.

Die Fähigkeit kann pro xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase[Kampfphase] nur einmal angewendet werden.
Besitzt eine Kreatur diese Fähigkeiten mehrfach für unterschiedliche Attacken, dann muss sie auswählen, welchen Attacke sie verwenden will.

Jede Attacke wird nach den üblichen Regeln separat durchgeführt.
Zwischen den einzelnen Angriffen kann die Kreatur jedoch keine anderen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktionen] durchführen.
Erst nach Abschluss des Mehrfach-Angriffs kann die Kreatur wieder andere Aktionen durchführen.

.Mehrfach-Attacke
====
Eine Kreatur besitzt die Mehrfach-Attacke (Biss, 4) und die Fähigkeit link:bestiary_skill_attack_bite.adoc[Biss (8, 3W6+1)].
Dank dieser Fähigkeit kann die Kreatur mit nur einer xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] die Fähigkeit Biss 4-mal in ihrem xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[Zug] einsetzen.
Jeder einzelne Biss kann gegen ein- und dieselbe Kreatur geführt werden oder gegen alle Kreaturen, die in xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_condition_bondedincombat[Reichweite] sind.
