= Waldwanderer

*Voraussetzungen:* - +
*Typ:* Bewegung +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur ist das Leben im Dickicht von Wäldern gewöhnt und besitzt möglicherweise besondere Klauen oder Fortbewegungsmittel, um sich mühelos durch dichtes Gestrüpp zu bewegen.

Sie erleidet keine Einschränkungen ihrer xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attributes_secondary_movementrate[BEW], wenn sie durch xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_movement_difficultterrian[schwieriges Gelände] bewegt, dass aufgrund von Pflanzenwuchs entstand und sie sich im Wald befindet.
Im Ermessen des SL können auch magische Effekte, die diese verursachen, ausgenommen werden.
