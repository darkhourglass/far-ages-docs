= Mehr Aktionen (Anzahl)

*Voraussetzungen:* - +
*Typ:* - +
*CP:* tba +

Die Kreatur kann pro xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase[Kampfphase] mehr als eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] ausführen.
Die Kreatur hat somit die angegebene *Anzahl* an Aktionen pro Kampfphase.

Dieser Bonus gilt nicht für xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktionen].
