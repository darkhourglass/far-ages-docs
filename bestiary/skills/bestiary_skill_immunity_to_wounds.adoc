= Immun gegenüber Wunden und Verletzungen

*Voraussetzungen:* - +
*CP:* tba +

Die Kreatur erleidet keine negativen xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds_steps[Effekte] durch xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds[Verletzungen].
