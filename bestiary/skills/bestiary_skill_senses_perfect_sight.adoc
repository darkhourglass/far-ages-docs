= Perfekte Sicht

*Voraussetzungen:* - +
*Typ:* Passiv, Sinn +
*Überanstrengung:* - +
*CP:* tba +

Eine Kreatur mit dieser Fähigkeit besitzt ein übernatürliches Gespür für den physikalischen Raum.
Sie ignoriert alle negativen Modifikatoren auf Angriffswürfe, die durch xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_coverage[Deckung] entstehen.

Ausschließlich totale Deckung gewährt den üblichen Schutz.
