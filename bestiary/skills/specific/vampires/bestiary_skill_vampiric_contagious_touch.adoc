= Infektiöse Berührung

*Voraussetzungen:* Sekundärer Kreaturentyp link:../../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_vampire.adoc[Vampir]
*CP:* tba +
*Aktivierung:* xref:../../../../rules/core/core_rules_battlesystem.adoc#ref_battle_actions[Aktion], xref:../../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_vampire.adoc#ref_vampire_rules_bloodcosts[Blut] 3

Du fokussierst das Blut in Deinem Körper auf alles Krankhafte, Zersetzende und Fieberiges.
Eine faule Energie jagt durch Deine Adern und überträgt sich auf eine Kreatur, die Du berührst.
Nutzt Du diese Fähigkeit im Nahkampf und Dein Ziel kann sich wehren, musst Du eine Probe in xref:../../../../rules/core/core_rules_talents_base.adoc#ref_talents_unarmed_combat[Unbewaffneter Kampf] ablegen.
Du gilst in diesem Fall als xref:../../../../rules/core/core_rules_battlesystem.adoc#ref_battle_modifiers_missingweapon[bewaffnet].

Die berührte Kreatur muss sofort einen Rettungswurf gegen xref:../../../../rules/core/core_rules_d10_system.adoc#ref_core_base_saves_sicknessresist[Krankheit] ablegen.
Die Anzahl der nötigen Erfolge hängt wie folgt von Deine xref:../../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_vampire.adoc#ref_vampire_rules_powerlevel[Machtstufe] ab:

|===
|Machtstufe |Anzahl Erfolge

|1-2
|1

|3-5
|2

|6-7
|3

|8-9
|4

|10+
|5
|===

Besteht die Kreatur den Rettungswurf nicht, wird sie durch eine vorgegebene oder zufällig bestimmte Krankheit betroffen:

|===
|1W10 |Krankheit

|1-2
|xref:../../../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases_bloodcough[Bluthusten]

|3-4
|xref:../../../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases_tombfever[Grabfieber]

|5-6
|tba

|7-8
|tba

|9-10
|tba
|===

[NOTE]
Die Vorgabe, welche Krankheit durch diese Fähigkeit übertragen wird, findet sich normalerweise im Profil der Kreatur.
Sollte diese Vorgabe nicht explizit vorhanden sein, kann der SL entweder eine Vorgabe bestimmen oder die oben genannte Tabelle verwenden.
