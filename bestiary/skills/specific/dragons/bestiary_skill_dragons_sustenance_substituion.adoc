= Nahrungssubstitution

*Voraussetzungen:* link:../../../../rules/advanced/creaturetypes/primary/creaturetype_primary_dragon.adoc[Drache] +
*Machtstufe:* 3 +
*Typ:* Drachen, Übernatürlich +
*CP:* tba +
*Aktivierung:* Passiv +

Im Zuge ihrer Entwicklung zu einem Volk von Sternen-Reisenden haben die Drachen aufgrund der langen Reisen durch den Weltraum eine Möglichkeit entwickelt, ihren Bedarf an Nahrung durch Magie zu substituieren.
Ein Drache muss keine Nahrung, also weder Essen noch Wasser, zu sich nehmen, allerdings benötigt er stetigen Zugang zum Aether.
Ein Anti-Magisches Feld oder eine Ebene ohne Magie zwingt den Drachen dazu, normale Nahrung zu sich zu nehmen.
Der Drache kann immer freiwillig Nahrung aufnehmen.
