= Drachenpanzer

*Voraussetzungen:* link:../../../../rules/advanced/creaturetypes/primary/creaturetype_primary_dragon.adoc[Drache], link:bestiary_skill_dragons_dragons_scales.adoc[Drachenschuppen] +
*Machtstufe:* 6 +
*Typ:* Drachen +
*CP:* tba +
*Aktivierung:* Passiv +

Immer wenn ein Drache in seinem xref:../../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_tp[TP-Pool] eine xref:../../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_conditions_and_thresholds[Schwelle] überschreitet, erhält einen xref:../../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] auf den xref:../../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_fortitude[Körper-Rettungswurf].
Der Drachenpanzer bietet keine Vorteile, wenn der xref:../../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_death[Tod] eintritt, der TP-Pool als 0 erreicht.
