= Hinterlässt keine Leiche

*Voraussetzungen:* - +
*Typ:* Übernatürlich, Passiv +
*Überanstrengung:* - +
*CP:* tba +

Wenn diese Kreatur xref:../../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_death[stirbt] hinterlässt sie keinen Leichnam.
Ihr Körper zerfällt beispielsweise zu Staub oder Asche.
Dies hat zur Folge, dass Nekromanten den Leichnam nicht nutzen können, um einen Untoten zu erschaffen.
Grundsätzlich alle Zauber, die eine Leiche erfordern, können auf die Kreatur nach ihrem Ableben nicht angewandt werden.
