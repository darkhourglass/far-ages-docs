= Gefolgschaft(Kreaturen, Rolle)
*Voraussetzungen:* - +
*Typ:* passiv +
*Überanstrengung:* - +
*CP:* 5000 + Summe über aller CP der *Kreaturen* +
Diese Kreatur wird von einer Gefolgschaft von *Kreaturen* begleitet. Je nach angegebener *Rolle* werden sich die Kreaturen gegenüber anderen, wie z.B. den Charakteren verhalten. Folgende Rollen können im Rahmen diese Fähigkeit vergegen werden:
* *Diener:* Die Kreaturen erledigen jeden Befehl oder Wunsch der Kreatur, jedoch nur soweit ihr eigenen Leben und körperliche Unversehtheit nicht in Gefahr ist. Sie werden sich aus K#mpfen zurückziehen.
* *Leibwächter:* Die Kreaturen werden sich am Kampf beteiligen und jeden Angreifer auf die Kreatur bekämpfen.
