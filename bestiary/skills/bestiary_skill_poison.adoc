= Gift (Attacke, Gift)

*Voraussetzungen:* - +
*Typ:* Magisch +
*Überanstrengung:* - +
*CP:* tba +
Die Kreatur kann über ihre angebene *Attacke* das angebene *Gift* verteilen. Doe Kreatur kann ihre *Attacke* nach den üblichen Regeln einsetzen.
Eröaht sie einen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_hits_automatic_hit[Treffer], kommt die getroffene Kreatur zum ersten Mal xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_resist[in Kontakt mit dem Gift].
Manche Gifte erfordern Kontakt zum Blut.
In diesen Fällen muss die *Attacke* xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagerolls[Schaden] verursacht haben.
