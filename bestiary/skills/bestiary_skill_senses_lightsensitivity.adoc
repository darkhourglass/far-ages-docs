= Lichtempfindlich

*Voraussetzungen:* - +
*Typ:* Passive, Sinn +
*Überanstrengung:* - +
*CP:* tba +

Die Kreatur ist sehr empfindlich gegenüber Licht.
Dies äußert sich, dass sie von hellem Licht geblendet wird, aber auch mit wenig Restlicht in der Dunkelheit deutlich besser sehen kann, als die meisten anderen Lebewesen.

Alle xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_malus[Mali] aufgrund von xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_darkness[Dunkelheit] werden halbiert (abgerundet).

Befindet sich die Kreatur in direktem Licht, zum Beispiel Sonnenlicht oder auch Fackelschein, dann erleidet sie einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_malus[Malus] auf ihre Würfe zum Erfolg von -5 bis -15.
Je heller das Licht, umso größer der Malus.
Dies kann im Ermessen des SL bestimmt werden, der höchste Malus sollte beispielsweise bei direktem, hellen Sonnenlicht angewendet werden, der niedrigste bei hellem Fackelschein oder in einem erleuchteten Raum.
