= Furcht (Angriffsstufe)

*Voraussetzungen:* - +
*Typ:* Magisch +
*CP:* tba +

Die Kreatur hat eine unheilvolle Präsenz, vielleicht durch eine magische Aura oder wie ein Drache durch lautes Gebrüll, dass die andere erschüttern vermag.

Um Furcht einzusetzen, würfelt die Kreatur eine xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] und jedes Ziel einen konkurrierende xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_check_saves_base_fear[Furcht-Rettungswurf].

Verwendet die Kreatur Furcht als xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_actions[Aktion], sind alle anderen Kreaturen um Umkreis von 18,00 Metern betroffen.
Alternativ kann die Kreatur Furcht als xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_movefightaction[Bewegungsmanöver] gegen eine einzige Kreatur in 18,00 Metern Reichweite einsetzen.
