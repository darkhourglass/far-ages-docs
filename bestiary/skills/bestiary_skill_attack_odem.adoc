= Odem (Angriffsstufe, Schaden, Schadensart, Reichweite)

*Voraussetzungen:* - +
*Typ:* Angriff, EN +
*CP:* tba +

Die Kreatur besitzt eine Atemwaffe, die sie gegen ihre Gegner einsetzen kann.
Besonders bekannt für diese Art des Angriffs sind xref:../../rules/advanced/creaturetypes/primary/creaturetype_primary_dragon.adoc[Drachen] mit ihrem feurigen Atem.

Die Atemattacke kann als xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] in einer Kampfphase eingesetzt werden.

Die Angriffsprobe wird mit der angegebenen *Angriffsstufe* gewürfelt.
Diese enthält bereits alle Boni aus den Attributen und Talenten der Kreatur.
Dabei gelten die Regeln für xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_throwingweapons_cone[kegelförmige] Angriffe.
Der Kegel hat dabei eine Ausdehnung gemäß der angegebenen *Reichweite* oder 1,50 Meter pro Stufe in xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_energy[EN].

Die Schadensprobe wird mit dem angegebenen *Schaden* gewürfelt, wobei der angegebene xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetypes[*Schadenstyp*] verursacht wird.
Sollte keine Schadenwürfel angegeben sein, wird die Schadensprobe mit 1W6 pro EN-Stufe gewürfelt.

Kreaturen im Wirkungsbereich dürfen einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_reflex[Reflex-Rettungswurf] gegen das Ergebnis der Angriffsprobe ablegen.
Bei einem Erfolg können sie den versuchten Schaden halbieren.

.Atemattacke
====
Ein Drache hat eine Atemattacke (14, 4W10+8, Feuer, 9,00).
Für seine Angriffsprobe würfelt er 2W10+14 und spuckt einen 9,00 Meter Kegel Feuer, der 4W10+8 Schaden verursacht.
====
