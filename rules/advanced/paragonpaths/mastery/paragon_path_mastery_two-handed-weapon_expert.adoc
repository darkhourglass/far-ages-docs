= Bihänder Experte

== Beschreibung


== Voraussetzungen

Um Bihänder Experte Stufe 1 zu lernen, muss ein Charakter folgende Voraussetzungen erfüllen:

* xref:../../../core/core_rules_talents_base.adoc#ref_talents_meleeweapons[Nahkampfwaffen] auf Stufe 3
* link:../../../core/skills/core_skill_weapontraining_melee.adoc[Waffentraining] mit einer Zweihand-Waffe

== Stufen lernen
Bihänder Experten können ohne Beschränkungen Stufen lernen.

== Stufe 1

Bihänder Experten erhalten keine Vorgaben für die Stufe 1.

== Maximale Stufe

Der Schicksalspfad des Bihänder Experten gibt keine maximale Stufe vor.
