= Der Hunger (Stark, Bedürfnis)

*Typ:* Stark
*Ziel:* Kreatur
*Ende:* Permanent, Bann
*Beschreibung:* Dieser Fluch ist die stärkere Version von dem Fluch ...
Diese Version funktioniert identisch, allerdings kann die betroffene Kreatur keine TP auf natürliche Weise, wie zum Beispiel durch xref:../../core/core_rules_2d10_system.adoc#ref_core_2d10_regeneration[Regeneration], wiederbekommen.
Nur wenn sie das Bedürfnis stillt, regeneriert sie 1W10 TP pro KO-Stufe.

Die Kreatur wird von einem nagenden Hunger nach dem angegebenen *Bedürfnis* gequält.
Das Bedürfnis ist nicht unbedingt überlebensnotwendig, noch muss es sonderlich umgänglich sein.
Üblicherweise ist das Bedürfnis eine bestenfalls bedenkliche Zutat, zum Beispiel Blut, menschliche Herzen oder Knochen.
Möchte die Kreatur dem Hunger widerstehen, muss sie einen xref:../../core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_discipline[Willenskraft-Rettungswurf] bestehen.
Der xref:../../core/core_rules_2d10_system.adoc#ref_core_2d10_checks_miniumroll[Mindestwurf] erhöht sich jedes Mal um 1, wenn die Kreatur dem Hunger widersteht.
Gibt ihm nach, startet der Mindestwurf wieder beim xref:../../core/core_rules_2d10_system.adoc#ref_core_2d10_checks_standardminiumroll[SMW].
Misslingt die Probe, verfällt die Kreatur in xref:../../core/core_rules_2d10_system.adoc#ref_core_2d10_condition_frenzy[Raserei], bis sie das Bedürfnis befriedigen konnte.
