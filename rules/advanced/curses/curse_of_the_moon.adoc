= Fluch des Mondes

*Typ:* Schwach, Stark, Todesfluch
*Ziel:* Kreatur
*Ende:* Permanent, Bann, Tat
*Beschreibung:* Die Kreatur ist verflucht, im Licht des Mondes zu leiden.
Der Fluch tritt ein, wenn die Kreatur im direkten Licht des Mondes steht.
Befindet sich die Kreatur im Schatten eines hinreichend großen Hindernisses, wie beispielsweise eine Hauswand, ist sie geschützt.
Auch indirektes Licht verursacht keinen negativen Effekt.

Der Effekt richtet sich nach dem Typ des Fluches:

[[ref_curse_of_the_moon_weak]]
== Schwach
Die Kreatur erleidet einen Malus von -1 auf die Würfe zum Erfolg auf alle Proben.
Außerdem erhält sie jede xref:../../core/core_rules_battlesystem.adoc#ref_battle_battlephase[Kampfphase], in der sie im Licht des Mondes steht, 1 Punkt xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_inevitable[unabwendbaren] xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_type_elemental_fire[Feuer] Schaden.

[[ref_curse_of_the_moon_strong]]
== Stark
Die Kreatur erleidet einen Malus von -2 auf die Würfe zum Erfolg auf alle Proben.
Außerdem erhält sie jede xref:../../core/core_rules_battlesystem.adoc#ref_battle_battlephase[Kampfphase], in der sie im Licht des Mondes steht, 1W10 Punkte xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_inevitable[unabwendbaren] xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_type_elemental_fire[Feuer] Schaden.

[[ref_curse_of_the_moon_deathcurse]]
== Todesfluch
Die Kreatur erleidet einen Malus von -3 auf die Würfe zum Erfolg auf alle Proben.
Außerdem erhält sie jede xref:../../core/core_rules_battlesystem.adoc#ref_battle_battlephase[Kampfphase], in der sie im Licht des Mondes steht, 2W10+2 Punkte xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_inevitable[unabwendbaren] xref:../../core/core_rules_battlesystem.adoc#ref_battle_damage_type_elemental_fire[Feuer] Schaden.
