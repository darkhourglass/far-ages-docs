[[ref_core_backrounds_echo_recall_memory]]
== Rufe Erinnerung
Wenn Du eine xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_talentchecks[Talent-Probe] ablegst, kannst Du entscheiden, ob Du eine Erinnerung aus einem früheren Leben rufen möchtest.
In diesem Fall erhältst Du einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] auf diese Probe.
Nach dem Einsatz dieser Fähigkeit benötigst Du eine xref:../core_rules_2d10_system.adoc#ref_core_2d10_regeneration_long_rest[lange Rast], um sie erneut einsetzen zu können.
