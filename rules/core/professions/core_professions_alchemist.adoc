[[ref_core_professions_alchemist_create_bombs]]
== Bomben herstellen
Der Alchemist lernt die besondere Fähigkeit Bomben herzustellen.
Bomben im Sinne dieser Fähigkeit sind kleine, mit alchemistischer Mixtur, gefüllte Behälter, die einen bestimmten Effekt in einem Umkreis bei Auslösung verursachen.
Die Auslösung erfolgt im Allgemeinen durch Werfen und bei Aufprall.

Um eine Bombe herzustellen, wählt der Alchemist einen Zauberspruch aus der Zauberschule xref:../core_rules_magic_base.adoc#ref_core_magic_schools_alchemy[Alchemie], den er gelernt hat.
Dieser Zauberspruch muss als Ziel mindestens eine Kreatur sein, dabei gilt auch "Selbst" als valide.
Eine fertige Bombe wird als xref:../core_rules_battlesystem.adoc#ref_core_battle_throwingweapons_aoe[Wurfwaffe mit Radius] mit einer xref:../core_rules_battlesystem.adoc#ref_core_battle_projectiles_baserange[Grundreichweite] von 12,00 Metern behandelt.
Der Radius beträgt immer 3 Meter, auch wenn der eigentliche Effekt keinen Radius hatte.
Anstelle einer Spruchzauberei-Probe würfelt der Alchemist eine Wurfwaffen-Probe und behandelt den Bombenwurf so als hätte er den entsprechenden Zauberspruch ausgesprochen.
Dieser wirkt nun in dem Effektradius der Bombe.

Einmal pro Tag darf der Alchemist eine Bombe ohne Materialkosten herstellen.
Ansonsten kosten Bomben pro POT des gewählten Zauberspruches 1000 Goldmünzen.

== Gift-Resistent
Ein Alchemist erhält einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] auf alle Proben, um einem xref:../core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_resist[Giften zu widerstehen].

[[ref_core_professions_alchemist_potion_knowledge]]
== Wissen über Substanzen
Der Alchemist kann aufgrund von Geruch, Aussehen und Geschmack so ziemlich jede Flüssigkeit identifizieren.
Er muss dazu die zu identifizierende Flüssigkeit untersuchen und eine Probe auf xref:../core_rules_talents_base.adoc#ref_talents_knowledge[Wissen (Alchemie)] würfeln.

Dabei gilt, dass nicht-magische Flüssigkeiten im Allgemeinen einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_tiersofsuccess[durchschnittlichen Erfolg] erfordern, um identifiziert zu werden.
Exotische, nicht-magische Flüssigkeiten können nach Ermessen des SL einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_tiersofsuccess[höheren Erfolgsgrad] erfordern.
Das Identifizieren von magischen Tränken folgt den üblichen xref:../core_rules_magic_base.adoc#ref_magic_items_identification[Regeln], es wird jedoch das Wissens-Talent verwendet.

Sofern nicht anders angegeben, erfolgt die Identifikation sofort.
Sollte der Alchemist die Flüssigkeit nicht identifizieren können, kann er es erst nach Ablauf von 24 Stunden noch einmal versuchen.
