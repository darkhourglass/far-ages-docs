[[ref_core_professions_brawler_opportunist]]
== Opportunist
Ist der Ringer mit einem Gegner im Nahkampf xref:../core_rules_2d10_system.adoc#ref_core_2d10_condition_bondedincombat[gebunden] und hat er xref:../core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[in seinem Zug] eine Aktion verwendet, um einen unbewaffneten Angriff durchzuführen, kann er einen weiteren unbewaffneten Angriff gegen den gleichen Gegner als xref:../core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktion] ausführen.

[[ref_core_professions_brawler_versatile_fightingstyle]]
== Vielseitiger Kampfstil
Ein Ringer kann vor dem Werfen einer Probe in dem Talent xref:../core_rules_talents_base.adoc#ref_talents_unarmed_combat[Unbewaffneter Kampf] _immer_ entscheiden, ob er als verwandtes Attribut ST oder GE verwenden möchte.
Diese Wahl keine Auswirkung auf eine nachfolgende xref:../core_rules_battlesystem.adoc#ref_core_battle_damage_damagerolls[Schadensprobe].
Die Entscheidung gilt für alle weiteren Proben in der aktuellen Kampfphase.
