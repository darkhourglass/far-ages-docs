== Eigenschaften

[[ref_warrior_adaptivestrategy]]
=== Adaptive Strategie
Zu Beginn einer Kampfphase darf ein Krieger entscheiden, ob er einen defensiven oder offensiven Kampfstil annehmen möchte.
Die Entscheidung muss mit xref:../core_rules_battlesystem.adoc#ref_battle_battleround_actions[Beginn] der Aktion des Kriegers fallen.
Die Entscheidung gilt für den Rest der Kampfphase. +
Wählt der Krieger einen *defensiven* Kampfstil, erhält er einen Bonus von +1 auf die Würfe zum Erfolg für die Talente xref:../core_rules_talents_base.adoc#ref_talents_evade[Hieb ausweichen], xref:../core_rules_talents_base.adoc#ref_talents_parade[Parade] und xref:../core_rules_talents_base.adoc#ref_talents_shield_defense[Schildverteidigung].
Gleichzeitig erhält er einen Malus von -1 auf die Würfe zum Erfolg auf die Talente xref:../core_rules_talents_base.adoc#ref_talents_meleeweapons[Nahkampfwaffen], xref:../core_rules_talents_base.adoc#ref_talents_projectileweapons[Projektilwaffen] und xref:../core_rules_talents_base.adoc#ref_talents_throwingweapons[Wurfwaffen].
+
Wählt der Krieger hingegen einen *offensiven* Kampfstil, werden die Boni bzw. Mali des zuvor beschriebenen defensiven Kampfstils getauscht.

[[ref_warrior_favoritefightingstyle]]
=== Bevorzugte Kampfweise
Zu Beginn des Spiels wählt der Krieger einen der folgenden Kampfstile:

* xref:../../tables/items/table_items_meleeweapons.adoc[Einhandwaffe]
* xref:../../tables/items/table_items_heavymeleeweapons.adoc[Schwere Nahkampfwaffe] bzw. Zweihandwaffe
* xref:../../tables/items/table_items_projectileweapons.adoc[Schwere Projektilwaffe]
* xref:../../tables/items/table_items_throwingweapons.adoc[Wurfwaffe]

Kämpft er mit einer passenden Waffe bzw. Kombination aus Waffen und Schild, darf er in einer Kampfphase für den Einsatz eines xref:../core_rules_battlesystem.adoc#ref_battle_movefightaction[Bewegungsmanövers] eine weitere Angriffsprobe mit dieser Waffe führen.
Die Fähigkeit ist nicht einsetzbar, wenn er keine passende Waffe führt.

[[ref_warrior_heatofthebattle]]
=== In der Hitze des Gefechts
Ein Krieger kann nach dem Würfeln einer beliebigen xref:../core_rules_d10_system.adoc#ref_core_attackingroll[Angriffsprobe] entscheiden entweder einen gewürfelten Patzer oder beliebige Misserfolge neu zu würfeln.
Die entsprechenden Würfel werden mit den identischen Modifikatoren neu gewürfelt. +
Der Krieger muss das neue Ergebnis akzeptieren, auch wenn es schlechter ist, als zuvor.
Er muss diese Fähigkeit einsetzen, bevor eine etwaige xref:../core_rules_d10_system.adoc#ref_core_defendingroll[Verteidigungsprobe] gewürfelt wird. +
Pro Tag kann er diese Fähigkeit so oft einsetzen wie er Stufen in xref:../core_rules_charactercreation.adoc#ref_attribute_selfcontrol[SB] hat, jedoch maximal einmal pro xref:../core_rules_battlesystem.adoc#ref_battle_battlephase[Kampfphase].

[[ref_warrior_unbreakable]]
=== Unverwüstlich
Ein Krieger erhält einen einmaligen Bonus von 15 Punkten auf sein xref:../core_rules_charactercreation.adoc#ref_secondary_hitpoints[Trefferpunkte]-Pool.
