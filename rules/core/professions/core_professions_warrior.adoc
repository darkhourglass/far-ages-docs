[[ref_core_professions_warrior_adaptive_strategy]]
== Adaptive Strategie
Zu Beginn einer Kampfphase darf ein Krieger entscheiden, ob er einen defensiven oder offensiven Kampfstil annehmen möchte.
Die Entscheidung muss mit xref:../core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[Beginn] der Aktion des Kriegers fallen.
Die Entscheidung gilt für den Rest der Kampfphase.

Wählt der Krieger einen *defensiven* Kampfstil, erhält er einen Bonus von +3 auf die Proben für die Talente xref:../core_rules_talents_base.adoc#ref_talents_evade[Ausweichen], xref:../core_rules_talents_base.adoc#ref_talents_parade[Parade] und xref:../core_rules_talents_base.adoc#ref_talents_shield_defense[Schildverteidigung].
Gleichzeitig erhält er einen Malus von -3 auf Proben für die Talente xref:../core_rules_talents_base.adoc#ref_talents_meleeweapons[Nahkampfwaffen], xref:../core_rules_talents_base.adoc#ref_talents_projectileweapons[Projektilwaffen] und xref:../core_rules_talents_base.adoc#ref_talents_throwingweapons[Wurfwaffen].

Wählt der Krieger hingegen einen *offensiven* Kampfstil, werden die Boni bzw. Mali des zuvor beschriebenen defensiven Kampfstils getauscht.

[[ref_core_professions_warrior_favorite_fighting_style]]
== Bevorzugte Kampfweise
Zu Beginn des Spiels wählt der Krieger einen der folgenden Kampfstile:

* xref:../core_rules_battlesystem.adoc#ref_core_battle_items_weapons[Einhandwaffe]
* xref:../core_rules_battlesystem.adoc#ref_core_battle_items_weapons_tag_heavy[Schwere Nahkampfwaffe]
* xref:../core_rules_battlesystem.adoc#ref_core_battle_items_weapons[Schwere Projektilwaffe]
* xref:../core_rules_battlesystem.adoc#ref_core_battle_items_weapons[Wurfwaffe]

Kämpft er mit einer passenden Waffe, darf er in xref:../core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[seinem Zug] einen weiteren xref:../core_rules_battlesystem.adoc#ref_core_battle_actions_attacks[Angriff] als xref:../core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktion]

[[ref_core_professions_warrior_heat_of_the_battle]]
== In der Hitze des Gefechts
Ein Krieger kann nach dem Würfeln einer beliebigen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_concurrentrolls_attackingroll[Angriffsprobe] entscheiden entweder einen gewürfelten Patzer oder Misserfolg neu zu würfeln.

Der Krieger muss das neue Ergebnis akzeptieren, auch wenn es schlechter ist, als zuvor.
Er muss diese Fähigkeit einsetzen, bevor eine etwaige xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_concurrentrolls_defendingroll[Verteidigungsprobe] gewürfelt wird.

Pro Tag kann er diese Fähigkeit so oft einsetzen wie er Stufen in xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_selfcontrol[SB] hat, jedoch maximal einmal pro xref:../core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase[Kampfphase].
