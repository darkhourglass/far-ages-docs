= Krieger

*Beschreibung:* +
*Talentliste (SGM 1):* Athletik, Niederschlag Widerstehen, 1 freies Handwerkstalent +
*Talentliste (SGM 2):* Projektilwaffen, Verborgenes Entdecken, Willenskraft, 1 freies Wissenstalent +
*Attributsbonus:* +1 ST +
*TP/MP-Steigerung:* +9/+3 +
*Voraussetzungen:* +
*Startausrüstung:* +
*CP:* 60 +

== Eigenschaften

=== Kriegerspezialisierung
Bei der Charaktererschaffung muss der Charakter eine der folgenden Spezialisierungen wählen und kann die jeweils gelisteten xref:../core_rules_talents_base.adoc[Talente] mit SGM 1 aufschreiben:

* *Bihänder*: Hieb Ausweichen, Nahkampfwaffen, Parade, Reiten, Wurfwaffen
* *Verteidiger*: Hieb Ausweichen, Nahkampfwaffen, Reiten, Schildverteidigung, Parade
* *Shao-Lin*: Akrobatik, Hieb Ausweichen, Reflex, Unbewaffneter Kampf, Wurfwaffen
* *Säbelrassler*: Akrobatik, Hieb Ausweichen, Nahkampfwaffen, Parade, Wurfwaffen

=== Kriegerfähigkeiten
Ein Krieger kann zur Charaktererschaffung eine der folgenden xref:../core_rules_skills.adoc[Fähigkeiten] ohne CP-Kosten lernen:

* xref:../core_rules_skills.adoc#ref_skills_acrobatic_attack[Akrobatischer Angriff]
* xref:../core_rules_skills.adoc#ref_skills_martial_I[Kampfkunst I]
* xref:../core_rules_skills.adoc#ref_skills_berserk_i[Kampfrausch I]
* Einen beliebigen Waffenfokus für xref:../core_rules_skills.adoc#ref_skills_weaponfocus_melee[Nahkampfwaffen], xref:../core_rules_skills.adoc#ref_skills_weaponfocus_projectile[Projektilwaffen] oder xref:../core_rules_skills.adoc#ref_skills_weaponfocus_throwing[Wurfwaffen]

Er muss dazu nicht die an der Fähigkeit angebenen Voraussetungen erfüllen.

=== In der Hitze des Gefechts
Ein Krieger kann nach dem Würfeln einer beliebigen xref:../core_rules_d10_system.adoc#ref_core_attackingroll[Angriffsprobe] entscheiden entweder einen gewürfelten Patzer oder beliebige Misserfolge neu zu würfeln.
Die entsprechenden Würfel werden mit den identischen Modifikatoren neu gewürfelt. +
Der Krieger muss das neue Ergebnis akzeptieren, auch wenn es schlechter ist, als zuvor.
Er muss diese Fähigkeit einsetzen, bevor eine etwaige xref:../core_rules_d10_system.adoc#ref_core_defendingroll[Verteidigungsprobe] gewürfelt wird. +
Pro Tag kann er diese Fähigkeit so oft einsetzen wie er Stufen in xref:../core_rules_charactercreation.adoc#ref_attribute_selfcontrol[SB] hat, jedoch maximal einmal pro xref:../core_rules_battlesystem.adoc#ref_battle_battleround[Kampfrunde].

=== Unverwüstlich
Ein Krieger erhält einen Bonus von 10 Punkten auf sein xref:../core_rules_charactercreation.adoc#ref_secondary_hitpoints[Trefferpunkte]-Pool.
