== Kriegerspezialisierung
Der Charakter kann eine der folgenden Spezialisierungen wählen und die gelisteten Talente mit SGM 1 aufschreiben:

* *Bihänder*: Hieb Ausweichen, Nahkampfwaffen, Parade, Reiten, Wurfwaffen
* *Verteidiger*: Hieb Ausweichen, Nahkampfwaffen, Reiten, Schildverteidigung, Parade
* *Shao-Lin*: Akrobatik, Hieb Ausweichen, Reflex, Unbewaffneter Kampf, Wurfwaffen
* *Säbelrassler*: Akrobatik, Hieb Ausweichen, Nahkampfwaffen, Parade, Wurfwaffen
