== Elementares Manifest beschwören
Basierend auf seinem xref:../core_rules_magic_base.adoc#ref_core_magic_schools_elementarism_elemenatalfocus[Elementarfokus] kann der Elementarist ein xref:../../../bestiary/elementals/bestiary_elementals_elemental_manifest.adoc[Manifest] der Machtstufe 1 beschwören.
Ist der Elementarfokus beispielsweise Feuer, so wird ein Feuer-Manifest beschwören.

Die Beschwörung erfordert eine xref:../core_rules_battlesystem.adoc#ref_core_battle_actions[Aktion] und den Einsatz von 5 MP.

Einmal beschworen, gehorcht das Manifest dem Elementarist für 24 Stunden und löst sich danach von selbst auf.
Mit dem Einsatz einer xref:../core_rules_battlesystem.adoc#ref_core_battle_freeactions[Freien Aktion] kann der Elementarist das Manifest auch vor Ablauf der 24 Stunden zurückschicken.

Es kann immer nur ein Manifest gleichzeitig durch den Elementarist beschwören werden.
Sofern es der Elementarist wünscht, wird sogar immer das gleiche Manifest beschwören.
