[[ref_core_professions_menestrel_magic_performance]]
== Magischer Auftritt
Besitzt der Menestrel ein weiteres Talent, welches den Gesang unterstützt (z.B. Kunst[Laute]), darf er die Spruchzauberei-Probe der als xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] würfeln.
Ein Menestrel kann keine Kunst-Talente kombinieren, wenn diese den Einsatz von Gesang nicht gleichzeitig ermöglichen (z.B. Kunst[Flöte]).
