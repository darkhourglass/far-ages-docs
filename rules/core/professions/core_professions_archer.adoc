= Schütze

*Attribute:* +1 GE, +1 ER +
*Talente:* Akrobatik, Athletik, Ausweichen, Handwerk[Bogen und Pfeile], Reiten, Schleichen, Projektilwaffen, Verborgenes Erkennen, Verstecken, Wurfwaffen, 1 freies Wissentalent +
*Fähigkeiten:* link:../skills/core_skill_trick_shot.adoc[Trickschuss] +
*TP/MP-Steigerung:* +6/+4 +
*Rettungswürfe:* xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_reflex[Reflex] +
*Startausrüstung:* Komposit-Bogen, Köcher mit 20 Pfeilen, Lederrüstung, 10 Wurfmesser, Rucksack +
*Eigenschaften:* <<ref_core_professions_archer_focus_shot,Fokussierter Schuss>>, <<ref_core_professions_archer_improvised_volley,Improvisierte Salve>> +
*Fortitudo:* 3 +

[[ref_core_professions_archer_focus_shot]]
== Fokussierter Schuss
Der Schütze fokussiert seine Konzentration auf den einen Schuss (oder Wurf), um auch schwer zu treffende Ziele anzugreifen.
Bei einer xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_concurrentrolls_attackingroll[Angriffsprobe] auf xref:../core_rules_talents_base.adoc#ref_talents_projectileweapons[Projektilwaffen] oder xref:../core_rules_talents_base.adoc#ref_talents_throwingweapons[Wurfwaffen] erhält der Schütze einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_bonus[Bonus] von +3 auf die Probe zu erhalten.
Er erleidet pro Einsatz dieser Fähigkeit 1 xref:../core_rules_battlesystem.adoc#ref_core_battle_damage_strain[Überanstrengungsschaden].
Die Fähigkeit kann nur einmal pro Kampfphase eingesetzt werden.

[[ref_core_professions_archer_improvised_volley]]
== Improvisierte Salve
Der Schütze versucht mit der Hilfe seiner schnellen Reflexe in kurzer Zeit 2 Projektile zu verschießen.
In xref:../core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase_own_turn[seinem Zug], wenn er eine xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_concurrentrolls_attackingroll[Angriffsprobe] auf xref:../core_rules_talents_base.adoc#ref_talents_projectileweapons[Projektilwaffen] oder xref:../core_rules_talents_base.adoc#ref_talents_throwingweapons[Wurfwaffen] erfolgreich durchgeführt hat, darf er eine weitere, identische Angriffsprobe gegen das gleiche Ziel würfeln.

Diese Probe erhält einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_malus[Malus] von -5.
Die Bedingung ist auch erfüllt, wenn die erste Probe getroffen, aber keinen Schaden verursacht hat.
Diese Fähigkeit kann nicht in Kombination mit <<ref_core_professions_archer_focus_shot>> verwendet werden.

Er erleidet pro Einsatz dieser Fähigkeit 1 xref:../core_rules_battlesystem.adoc#ref_core_battle_damage_strain[Überanstrengungsschaden].
Die Fähigkeit kann nur einmal pro Kampfphase eingesetzt werden.
