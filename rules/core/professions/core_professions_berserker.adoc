= Berserker

*Attribute:* +1 ST, +1 KO +
*Talente:* Athletik, Akrobatik, Ausweichen, Nahkampfwaffen, Unbewaffneter Kampf, Überleben, Willenskraft, Wurfwaffen, 1 freies Wissenstalent +

[[ref_core_professions_berserker_deathdenied]]
== Dem Tod trotzen
Erreicht der Berserker die xref:../core_rules_2d10_system.adoc#ref_core_2d10_death_condition_deathsdoor[Todesschwelle] seines xref:../core_rules_2d10_system.adoc#ref_core_2d10_pools_tp[TP-Pools], darf er entscheiden, diese Eigenschaft sofort einzusetzen.
Er erhält sofort KO+1W10 TP.

Diese Fähigkeit kann der Berserker nach Gebrauch erst nach einer xref:../core_rules_2d10_system.adoc#ref_core_2d10_regeneration_rest[Rast] wieder eingesetzt werden.

[[ref_core_professions_berserker_berserk_extended]]
== Verlängerter Kampfrausch
Jeder Kampfrausch aus der Fähigkeit link:../skills/core_skill_berserker.adoc[Berserker] dauert doppelt so lange.
Dies gilt auch für die fortführenden Fähigkeiten.
