== Eigenschaften

[[ref_gargoyle_freeze]]
=== Erstarren
Gargoyle besitzen die außergewöhnliche Eigenschaft, ihren Körper zum Erstarren zu bringen, so dass man sie von Statuen nicht unterscheiden kann.
Um diesen Zustand zu erreichen, muss der Gargoyle ein xref:../core_rules_battlesystem.adoc#ref_core_battle_maneuver[Manöver] einsetzen können.
Jegliche Mimik, Bewegung und subtile Motorik wird unterdrückt.
Gleichzeit wird die Haut noch fester und rauer, womit sie noch mehr Stein gleicht.

In diesem Zustand hat der Gargoyle keine Einschränkungen auf seine üblichen Sinne, auch seine Atmung funktioniert normal. Er kann keine Aktionen durchführen. Sein natürlicher Rüstungsschutz aus <<ref_gargoyle_hardasstone>> erhöht sich auf 10 Rüstungspunkte auf allen Treffenzonen.

Wechselt der Gargoyle in diese Form, würfelt er eine xref:../core_rules_talents_base.adoc#ref_talents_hide[Verstecken-Probe] mit einem xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_bonus[Bonus] von +10.
Jeder zukünftige Beobachter muss gegen des in dieser Probe gewürfelten Ergebnis eine xref:../core_rules_talents_base.adoc#ref_talents_discoverhidden[Verborgenes Entdecken-Probe] bestehen, um den Gargoyle von einer Statue zu unterscheiden.

Das Erstarren endet, wenn der Gargoyle eine Aktion durchführt oder spätestens nach 24 Stunden.

[[ref_gargoyle_hardasstone]]
=== Hart wie Stein
Die steinerne Haut eines Gargoyles gewährt ihm 3 Punkte xref:../core_rules_battlesystem.adoc#ref_core_battle_damage_naturalarmor[Natürlichen Rüstungsschutz] auf allen Trefferzonen.

[[ref_gargoyle_resilient]]
=== Resistent
Gargoyle erhalten einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] auf alle xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_base_poisonresist[Gift widerstehen]- und xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_base_sicknessresist[Krankheiten widerstehen]-Proben.

[[ref_gargoyle_unbreakable]]
=== Unverwüstlich
Der Charakter erhält einen Bonus von +2 xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_attributes_secondary_threshold[WID].
