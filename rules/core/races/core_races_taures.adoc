== Eigenschaften

=== Blut der Bestie

=== Außergewöhnliche Konstitution
Ihr muskulöser und stämmiger Körperbau lässt Tauren auch schwere Verletzungen besser aushalten.
Ein Taure besitzt einen Bonus von 25% auf seine TP.

=== Machtvolle Präsenz
Taure dürfen sich von dem Würfel einer xref:../core_rules_d10_system.adoc#ref_base_roll_intimidate[Einschüchtern] entscheiden, ob sie die Probe auf Basis ihrer ST- oder CH-Stufe würfen wollen. +
Besitzt er das Talent xref:../core_rules_talents_base.adoc#ref_talents_intimidate[Einschüchtern], so kann er diese Entscheidung ebenso treffen. Die Talentstufen werden zum gewählten Attribut addiert. +
Außerdem gewährt diese Eigenschaft einen Bonus von +1 auf die Würfe zum Erfolg auf alle Einschüchtern-Proben, wenn die betroffene Kreatur die Größe 6 oder niedriger hat.
