== Machtvolle Präsenz
Taure dürfen sich von dem Würfel einer xref:../core_rules_talents_base.adoc#ref_talents_intimidate[Einschüchtern] entscheiden, ob sie die Probe mit dem Attributsbonus ihrer ST- oder CH-Stufe würfen wollen.

Außerdem gewährt diese Eigenschaft einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil], wenn die betroffene Kreatur die xref:../core_rules_charactercreation.adoc#ref_core_characters_charactercreation_sizecategories[GK] 5 oder niedriger hat.
