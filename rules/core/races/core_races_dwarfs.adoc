= Zwerge

*Attributsbonus:* +1 KO, + 1 SB, -1 CH +
*Größe:* 4 +
*Primärer Typ:* link:../../advanced/creaturetypes/primary/creaturetype_primary_humanoid.adoc[Humanoid] +
*Sekundäre Typen:* link:../../advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[Lebend] +
*Generation:* 4 oder höher +
*Progenitor:* Titanten +
*CP:* 30 +

== Eigenschaften

=== Bollwerk
Zwerge erhalten Bonus von +2 auf ihre Attributseigenschaft xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_attributes_secondary_threshold[Widerstand].

=== Infrarotsicht
Zwerge erhalten die Fähigkeit link:../../../bestiary/skills/bestiary_skill_senses_infraredvision.adoc[Infrarotsicht].

=== Zwergische Begabung
Zwerge lernen eines der folgenden Talente mit SGM 1:

* xref:../core_rules_talents_base.adoc#ref_talents_disarmtraps[Fallen entschärfen]
* xref:../core_rules_talents_base.adoc#ref_talents_craft[Handwerk]
* xref:../core_rules_talents_base.adoc#ref_talents_discipline[Disziplin].

Die Wahl muss zur Charaktererfassung final getroffen werden.

=== Resistent
Zwerge erhalten einen xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_advantage[Vorteil] auf alle Proben, um xref:../core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_resist[Giften] oder xref:../core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_resist[Krankheiten] zu widerstehen.
