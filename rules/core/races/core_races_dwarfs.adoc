= Zwerge

*Attributsbonus:* +1 KO, + 1 SB, -1 CH +
*Größe:* 4 +
*Primärer Typ:* link:../../advanced/creaturetypes/primary/creaturetype_primary_humanoid.adoc[Humanoid] +
*Sekundäre Typen:* link:../../advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[Lebend] +
*Generation:* 4 oder höher +
*Progenitor:* Titanten +
*CP:* 30 +

== Eigenschaften

=== Bollwerk
Zwerge erhalten Bonus von +2 auf ihre Attributseigenschaft xref:../core_rules_charactercreation.adoc#ref_secondary_threshold[Widerstand].

=== Infrarotsicht
Zwerge erhalten die Fähigkeit link:../../../bestiary/skills/bestiary_skill_infraredvision.adoc[Infrarotsicht].

=== Zwergische Begabung
Zwerge lernen eines der folgenden Talente mit SGM 1: xref:../core_rules_talents_base.adoc#ref_talents_disarmtraps[Fallen entschärfen], xref:../core_rules_talents_base.adoc#ref_talents_craft[Handwerk] oder xref:../core_rules_talents_base.adoc#ref_talents_discipline[Disziplin]. +
Die Wahl muss zur Charaktererfassung final getroffen werden.

=== Zwergische Resistenz
Zwerge erhalten einen Bonus von +1 auf die Würfe zum Erfolg auf alle xref:../core_rules_d10_system.adoc#ref_core_base_saves_poisonresist[Gift widerstehen]- und xref:../core_rules_d10_system.adoc#ref_core_base_saves_sicknessresist[Krankheiten widerstehen]-Proben.
Um der Wirkung von Alkohol zu widerstehen, erhöht sich der Bonus auf +2.
