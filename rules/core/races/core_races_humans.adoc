== Eigenschaften

=== Freie Attributsstufe
Zur Charaktererschaffung erhalten Menschen einen Bonus von +1 Stufe auf ein frei wählbares Attribut.

=== Freie Talentstufe
Zur Charaktererschaffung erhalten Menschen einen Bonus von +1 Stufe auf ein frei wählbares Talent, welches sie mit SGM 1 oder 2 lernen.

=== Vielseitig interessiert
Zur Charaktererschaffung dürfen Menschen ein beliebiges Talent mit SGM 1 lernen, für dass sie die Voraussetzungen erfüllen.
