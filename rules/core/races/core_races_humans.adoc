== Vielseitigkeit
Zur Charaktererschaffung erhalten Menschen einen Bonus von +1 Stufe auf ein frei wählbares Attribut.

Zur Charaktererschaffung erhalten Menschen einen Bonus von +1 Stufe auf eines ihrer xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_talents_professional_talents[Berufstalente].

Zur Charaktererschaffung dürfen Menschen ein beliebiges Talent als xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_talents_professional_talents[Berufstalent] lernen, für dass sie die Voraussetzungen erfüllen.
