== Glück des kleinen Volkes
Das Schicksal scheint Halblingen besonders gewogen zu sein, so dass sie selbst aus misslichen Situationen besser herauskommen.
Für jede Stufe an xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_attribute_charisma[Charisma] kann ein Halbling einmal pro Tag eine Probe wiederholen, wenn diese ein Misserfolg oder Patzer war.
