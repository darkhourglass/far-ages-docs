= Aoehe

*Attributsbonus:* -1 ST, +1 GE, +1 ER +
*Größe:* 5 +
*Primärer Typ:* link:../../advanced/creaturetypes/primary/creaturetype_primary_humanoid.adoc[Humanoid] +
*Sekundäre Typen:* link:../../advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[Lebend] +
*Generation:* 4 oder höher +
*Progenitor:* Hrafass +
*CP:* 40 +

== Eigenschaften

=== Adleraugen
Aoehe erhalten einen Bonus von +3 auf alle Sicht-basieren xref:../core_rules_talents_base.adoc#ref_talents_discoverhidden[Verborgenes Erkennen-Proben].

=== Flügel
Ein Aoehe besitzt Flügel und kann damit fliegen.
Seine Bewegungsrate für das Fliegen entspricht seiner regulären BEW*2.
Ein Aoehe kann so viele Kampfphasen in der Luft bleiben, die seiner KO-Stufe multipliziert mit 20 entsprechen.
Der Charakter kann das Kampfmanöver xref:../core_rules_battlesystem.adoc#ref_core_battle_actions_attack_airattack[Flugangriff] verwenden.
