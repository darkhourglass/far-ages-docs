= Firbolg

*Attributsbonus:* +1 ST, +1 EN +
*Vorteile:* - +
*Nachteile:* - +
*Größe:* 5 +
*Sonstiges:* Alberons Schleier, Sprache der Natur +
*Generation:* 4 oder höher +
*Progenitor:* Alberon +
*CP:* 45 +

== Alberons Schleier
Firbolgs stehen unter besonderem Schutz durch Alberon.
Daher gewährt er Ihnen eine besondere Fähigkeit, die es ermöglicht, in Gefahrsituationen vor den Augen der Feinde zu verschwinden. +
Einmal am Tag darf ein Firbold als Freie Aktion in seiner Kampfphase Alberons Schleier aktivieren. Dazu muss er 5 MP einsetzen. +
Der Firbolg wird unsichtbar bis er einen Angriff durchführt, maximal jedoch seine EN-Stufe viele Kampfphasen.

== Sprache der Natur
Firbolgs haben die natürliche Begabung mit Tieren und Pflanzen zu kommunizieren.
Setzt ein Firbolg diese Fähigkeit ein, so verstehen Tiere und Pflanzen seine Worte.
Sie können aus seinen Worten seine Intention und Wünsche ableiten. +
Umgekehrt kann ein Firbolg jedoch nicht die Sprache von Tieren oder Pflanzen verstehen, sofern diese überhaupt vergleichbar kommunizieren. +
Ein Firbolg erhält dadurch einen Bonus von +1 auf die Würfe zum Erfolg auf alle CH-basierten Proben, die Tiere oder Pflanzen betreffen.
