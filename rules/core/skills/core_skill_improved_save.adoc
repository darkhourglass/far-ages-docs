= Verbesserter Rettungswurf (Rettungswurf)

*Voraussetzungen:* - +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* 100 +

Ein Charakter mit dieser Fähigkeit erhält einen permanenten xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_bonus[Bonus] von +3 auf den gewählten xref:../core_rules_2d10_system.adoc#ref_core_2d10_checks_saves[Rettungswurf].

Diese Fähigkeit kann mehrfach gelernt werden, jedoch nur einmal pro Rettungswurf.
