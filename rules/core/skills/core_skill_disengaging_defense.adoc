= Freimachende Verteidigung

*Voraussetzungen:* link:core_skill_agile.adoc[Agile], link:core_skill_battlesense.adoc[Kampfsinn], ein Verteidigungstalent mindestens auf Stufe 4 +
*Typ:* Bewegung, Verteidigung, Passiv +
*Überanstrengung:* - +
*CP:* 100 +
Wenn Du dich erfolgreich gegen einen xref:../core_rules_battlesystem.adoc#ref_core_battle_attacktypes_meleeattack[Angriff im Nahkampf] xref:../core_rules_battlesystem.adoc#ref_core_battle_reaction_use_defensive_talent[verteidigst], darft Du sofort eine xref:../core_rules_battlesystem.adoc#ref_core_battle_movement[Bewegung] einsetzen, um Dich von Deinem Angreifer wegzubewegen.
Deine Bewegung verursacht in der xref:../core_rules_battlesystem.adoc#ref_core_battle_melee_and_unarmed_zoneofcontroll[Bedrohungszone] des Angreifers keine xref:../core_rules_battlesystem.adoc#ref_core_battle_attacks_of_opportunity[Gelegenheitsangriffe], kann allerdings bei anderen Kontrahenten welche auslösen.
