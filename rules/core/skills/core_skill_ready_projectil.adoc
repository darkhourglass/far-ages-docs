= Projektil bereithalten

*Voraussetzungen:* link:core_skill_weapontraining_projectile.adoc[Waffentraining (Projektilwaffe)]  +
*Typ:* Angriff, Bonus-Aktion +
*Überanstrengung:* - +
*CP:* 100 +
Du hast gelernt ein Projektil für die Projektilwaffe Deines Waffentrainings so einzulegen, dass es extrem schnell einsatzbereit ist.
Der erste Angriff mit dieser so geladenen Waffe zählt als xref:../core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktion].
Danach musst Du die Waffe nach den üblichen Vorgaben xref:../core_rules_battlesystem.adoc#ref_core_battle_items_weapons_tag_ammunition[laden].
Der Einsatz der Fähigkeit erfordert eine xref:../core_rules_battlesystem.adoc#ref_core_battle_complexactions[komplexe Aktion].
