= Fremdsprache [eine Sprache]

*Voraussetzungen:* Lesen/Schreiben 2 +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP:* 100 +

Jede Sprache, die nicht die Muttersprache ist, gilt als Fremdsprache.
Die entsprechend gewählte Sprache kann dann gelesen und geschrieben werden.
Die Fähigkeit kann mehrmals gewählt werden, jeweils mit einer anderen Sprache.
Proben werden mit dem Talent Lesen/Schreiben gewürfelt.
