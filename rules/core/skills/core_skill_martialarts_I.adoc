= Kampfkunst I

*Voraussetzungen:* Unbewaffneter Kampf 1 +
*Überanstrengung:* -
*CP-Kosten:* 200 +
*Beschreibung:* Diese Fähigkeiten beschreiben einen Kampfstil, der ohne Waffen geführt wird und über den Unbewaffneten Kampf hinausgeht.
Dank intensivem Training wird der Charakter auch ohne Waffen ein gefährlicher Teilnehmer im Kampf.
Die xref:../core_rules_battlesystem.adoc#ref_battle_modifiers_missingweapon[Modifikatoren] für den Unbewaffneten entfallen.
Die unbewaffneten Attacken verursachen keinen Gelegenheitsangriff mehr, wenn sie gegen einen bewaffneten Gegner geführt werden.
