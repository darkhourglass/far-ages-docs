= Runenlehre

*Voraussetzungen:* Wissen[Geschichte] 2, Wissen[Arkanes] 4 +
*Typ:* Bewegung, Passiv +
*Überanstrengung:* - +
*CP:* 200 +

Runen sind ein altes Mittel, um Informationen weiter zugeben.
Einige Alphabete basieren nur auf Runen.
Einige Lebewesen bannen sogar Magie in Runen, um verschiedene, magische Effekte zu erwirken.
Charaktere mit dieser Fähigkeit können Runen erkennen, deuten und selber in Runen kodieren.
Jedoch können sie keine Magie in Runen bannen.
