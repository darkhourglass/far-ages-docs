*Typ:* Angriff +
*Überanstrengung:* - +
*CP:* 150 +
Führst Du einen xref:../core_rules_battlesystem.adoc#ref_core_battle_items_shields[Schild] kannst Du diesen nach den Regeln für xref:../core_rules_battlesystem.adoc#ref_core_battle_items_shields_as_improvised_weapons[Schilde als improvisierte Waffen] verwenden und erleidest nicht den vorgestellten Malus von -5 auf Deine Angriffsprobe.
