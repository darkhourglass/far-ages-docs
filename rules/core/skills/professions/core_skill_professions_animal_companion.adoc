= Tiergefährte

*Voraussetzungen:* Beruf +
*Typ:* Speziell +
*Überanstrengung:* - +
*CP:* - +

Der Charakter hat im Laufe seines Lebens zu einem Tier eine besondere Beziehung aufgebaut, dieses vielleicht von Geburt an gehütet.
Das Tier ist dem Charakter treu ergeben, jedoch sollte der Charakter dieses Vertrauen nicht missbrauchen.
Das Tier kann immer nur in seinen natürlichen Grenzen agieren, es besitzt also keine außergewöhnlichen Fähigkeiten.
Es kann jedoch Kommandos gelernt haben, die auch komplexere Aufgaben beinhalten.

Welche Tiere als Tiergefährten verfügbar sind, kann auf der folgenden link:../../../tables/table_animalcompandion.adoc[Tabelle] entnommen werden.
