= Reittier

*Voraussetzungen:* Beruf +
*Typ:* Speziell +
*Überanstrengung:* - +
*CP:* - +

Der Charakter besitzt ein Reittier, zum Beispiel ein Pferd.
Das Tier wurde für exakt die Aufgabe des Reitens trainiert.
Es ist das Tragen eines Sattels und Geschirr gewöhnt, trägt ohne Widerwillen einen Reiter und versteht seine Kommandos.

Weitergehende Stresssituationen ist das Reittier jedoch nicht gewöhnt.
Es nimmt nie aktiv an Kampfsituationen teil und versucht im Normalfall zu fliehen.

Die maximale GK des Reittiers beträgt die GK dies Besitzers + 1.
Welche Tiere als Reittiere verfügbar sind, kann auf der folgenden link:../../../tables/table_animalcompandion.adoc[Tabelle] entnommen werden.
