= Artefaktkunde

*Voraussetzungen:* Wissen[Arkanes] 5, Wissen[Legenden] 2, Wissen[Geschichte] 2 +
*Typ:* Bewegung, Passiv +
*Überanstrengung:* - +
*CP:* 200 +

Artefaktkunde ist eine Fähigkeit, die das Wissen um legendäre, magische Schätze umfasst.
Der Charakter kann anhand von äußeren Merkmalen oder Beobachtungen der Wirkungsweise von magischen Gegenständen mehr über diese herausfinden.
Dies können frühere Besitzer sein, Legenden, die sich um diesen Gegenstand ranken, oder einfach die Verwendungsweise.

Nützlich ist die Fähigkeit auch, wenn man den Verdacht hat, dass ein Fluch auf dem Gegenstand liegt.
Eine erfolgreiche Probe könnte dies aus der Geschichte des Artefakts bestätigen.
Der Erfolgsgrad dieser Probe kann vom SL aufgrund von Seltenheit des jeweiligen Artefakts abhängig gemacht werden.

Die Fähigkeit kann auch angewandt werden, wenn der Charakter mit Aether Wahrnehmung eine magische Aura eines Artefakts analysiert, um damit etwas über die magischen Eigenschaften eines unbekannten Gegenstandes zu erfahren.
Diese Anwendung ist nicht identisch mit Identifizieren.

Der Charakter kann technomantische Konstrukte als solche identifizieren, jedoch erhält durch diese Fähigkeit keine spezifischen Konstruktionsdetails.

Die Fähigkeit erweitert das Talent Wissen[Arkanes], allerdings darf der Charakter die Probe auch mit seinem Talent Wissen[Legenden] oder Wissen[Geschichte] würfeln.
