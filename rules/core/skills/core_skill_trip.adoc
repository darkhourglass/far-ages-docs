= Stolperfalle

*Voraussetzungen:* Nahkampfwaffen 3 oder Unbewaffneter Kampf 3, GE 2 +
*CP-Kosten:* 100 +
*Überanstrengung:* - +
*Beschreibung:*
Würfelt der Charakter eine Angriffsprobe mit Nahkampfwaffen oder Unbewaffneter Kampf gegen einen Gegner, kann er sich im Falle eines Erfolgs entscheiden, keinen Schadenswurf durchzuführen.
Tut er dies, würfelt er und sein Gegner eine konkurrierende GE-Probe.
Verliert der Gegner, verliert er seine verbliebenen Aktionen in dieser Kampfphase.
