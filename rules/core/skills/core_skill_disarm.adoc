= Entwaffnen
*Voraussetzungen:* Nahkampfwaffen 3 oder Unbewaffenter Kampf 3 +
*CP-Kosten:* 200 +
*Überanstrengung:* - +
*Beschreibung:*
Mit dieser Fähigkeit kannst Du versuchen, einem anderen Charakter die Waffe aus der Hand zu schlagen.
In diesem Fall erhälst Du einen Malus von *-1 auf die Würfe zum Erfolg* bei Deiner Angriffsprobe.
Ist die jeweilige Probe erfolgreich, würfeln beide Kontrahenten anstelle einer xref:../core_rules_battlesystem.adoc#ref_battle_damage[Schadensprobe] eine konkurrierende ST-Probe.
Hast Du mehr Erfolge, so fliegt die Waffe Deines Gegners 1W3*1,50 Meter weit weg in eine zufällig bestimmte Richtung.
