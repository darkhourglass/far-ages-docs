= Verspotten

*Voraussetzungen:* Überzeugen 3 +
*Typ:* Verbesserung (Aktion) +
*Überanstrengung:* - +
*CP:* 200 +

Diese Fähigkeit dient dazu einen Gegner, ob im Kampf im Redegefecht zu reizen und dazu zu unüberlegten Handlungen zu bewegen.

Das Talent Überzeugen wird in Verwendung mit Verspotten wird gegen eine SB-Probe des Opfers geworfen.

Für einen Erfolg erhält das Opfer einen Malus von -5 auf alle Proben für eine Anzahl an Kampfphasen gleich der Stufe des Überzeugen-Talents.
