= Verspotten

*Voraussetzungen:* Überzeugen 3 +
*Überanstrengung:* - +
*CP-Kosten:* 200 +
*Beschreibung:* Diese Fähigkeit erweitert das Talent Überzeugen.
Es dient dazu einen Gegner, ob im Kampf (im Kampf dauert diese Überzeugen-Probe 1 Kampfphase) oder im Redegefecht zu reizen und dazu zu unüberlegten Handlungen zu bewegen.
Das Talent Überzeugen wird in Verwendung mit Verspotten wird gegen eine Beherrschen-Proben des Opfers geworfen.
Für einen Erfolg erhält das Opfer einen Malus von -1 auf alle Würfe zum Erfolg für eine Anzahl an Kampfphasen gleich der Stufe des Überzeugen-Talents geteilt durch 2 (abgerundet, Minimum 1).
Hat der verspottende Charakter einen Guten Erfolg gewürfelt, beträgt der Malus -2, bei einem Sehr Guten -3 bis max. -4 bei einem Hervorragenden Erfolg.
