= Waffentraining [Nahkampfwaffe]
*Voraussetzungen:* Nahkampfwaffen 3 +
*Überanstrengung:* +-
*CP-Kosten:* 200 +
*Beschreibung:* Kämpft ein Charakter mit einer im Waffentraining gewählten Waffe, erhält er einen Bonus von +1 auf die Würfe zum Erfolg.
Die Auswahl erfolgt auf Basis einer bestimmten Waffenart, wie zum Beispiel Bastardschwert, Speer oder Dolch.
Diese Fähigkeit kann mehrfach gelernt werden, jedoch immer nur für eine andere Waffe.
