= Intuitive Magie

*Voraussetzungen:* Volk +
*Typ:* Passiv +
*Überanstrengung:* - +
*CP-Kosten:* - +

Alle Mitglieder dieses Volkes besitzen ein intuitives Bewusstsein für Magie und können deswegen auch ohne Ausbildung magische Effekte hervorrufen.
Zur Charaktererschaffung lernt der Charakter zwei xref:../core_rules_magic_base.adoc#ref_core_magic_base_arcanetrick[arkanen Tricks] aus einer beliebigen Zauberschule.
Für diese Zaubersprüche darf er eine xref:../core_rules_2d10_system.adoc#ref_core_2d10_characters_talents_untrainedcheck[ungeübte Anwendung] auf xref:../core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei] würfeln.
