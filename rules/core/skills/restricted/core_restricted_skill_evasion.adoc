= Ausweichmanöver

*Voraussetzungen:* Durch Schicksalspfad oder Beruf +
*Typ:* Bewegung, Passiv +
*Überanstrengung:* - +
*CP:* 100 +
Wenn Du durch einen erfolgreichen xref:../../core_rules_2d10_system.adoc#ref_core_2d10_checks_saves[Rettungswurf] bei einer xref:../../core_rules_battlesystem.adoc#ref_core_battle_damage_damagerolls[Schadenprobe] reduzierten, z,B. halbierten Schaden erhälst, erhälst Du dank dieser Fähigkeit gar keinen Schaden, wenn der Rettungswurf erfolgreich war.
