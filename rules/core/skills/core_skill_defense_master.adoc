= Verteidigungsmeister (Verteidigungstalent)

*Voraussetzungen:* Verteidigungstalent 6 +
*Typ:* Verteidigung, Passiv +
*Überanstrengung:* - +
*CP:* 100 +

Diese Fähigkeit wird für ein konkretes xref:../../core/core_rules_battlesystem.adoc#ref_core_battle_reaction_use_defensive_talent[Verteidigungstalent] gelernt.
Die Kreatur darf das gewählte Verteidigungstalent in einer xref:../../core/core_rules_battlesystem.adoc#ref_core_battle_cycle_battlephase[Kampfphase] beliebig oft gegen Angriffe einsetzen.
