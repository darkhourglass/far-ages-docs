= Kampfkunst III
*Voraussetzungen:* Unbewaffneter Kampf 6, Kampfkunst II +
*Überanstrengung:* -
*CP-Kosten:* 400 +
*Beschreibung:* Kampfkunst III eliminiert alle negativen Modifikationen, die ein
unbewaffenter Charakter im Kampf gegen einen bewaffneten Charakter erleidet.
Siehe dazu das Dokument link:../core_rules_battlesystem.adoc[Kampf]. +
Der Charakter erhält außerdem einen kumulativen Schadensbonus von +1 auf Schadenswürfe im unbewaffneten Kampf.
