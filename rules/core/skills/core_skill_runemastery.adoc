= Runenmeisterschaft (Rune)

*Voraussetzungen:* link:core_skill_runelore.adoc[Runenlehre], xref:../core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei(Runenmagie)] 5, Rune wurde xref:../core_rules_magic_base.adoc#ref_core_magic_schools_learning_spells[gelernt] +
*Typ:* Runen, Magie, Passiv +
*Überanstrengung:* - +
*CP:* 200 +
Die lernst diese Fähigkeit für eine konkrete *Rune*.
FÜr diese Rune erhältst Du die Möglichkeit den
xref:../core_rules_magic_base.adoc#ref_core_magic_schools_runes_rules_mastery_rune_effekt[Runenmeisterschafts Effekt] einzusetzen.
Diese Fähigkeit kann mehrfach gelernt werden, jedes Mal für eine andere *Rune*.
