=  Kampfkunst IV
*Voraussetzungen:* Unbewaffenter Kampf 9, Kampfkunst III +
*Überanstrengung:* -
*CP-Kosten:* 500 +
*Beschreibung:* Der Charakter erhält einen Bonus von +1 auf die Würfe zum Erfolg auf alle Proben in den Talenten Unbewaffneter Kampf, Hieb Ausweichen und Reflex, solange er keine Waffen trägt.+
Der Charakter erhält außerdem einen kumulativen Schadensbonus von +1 auf Schadenswürfe im unbewaffneten Kampf.
