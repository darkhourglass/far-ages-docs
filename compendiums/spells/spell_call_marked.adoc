= Rufe Gezeichnete

*Arkanes Geheimnis:* Nein +
*POT:* 11 +
*Rettungswurf:* siehe Beschreibung +
*Komponenten:* Formel, Gesten +
*Fokus:* Teleport, Geist +
*Vorbereitung:* 5 +
*Reichweite:* 3,00 Meter +
*Anzahl der Ziele:* siehe Beschreibung  +
*Dauer:* Sofort +
*Effekt:* +
Wähle ein Objekt oder eine Kreatur, die von einem Deiner link:spell_wizardsmark.adoc[Zaubererzeichen] markiert sind.
Wählst Du eine Kreatur, steht ihr ein xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_magic[Magie-Rettungswurf] zu.
Bei erfolgreicher xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_rules_spellcasting_roll[Spruchzauberei-Probe] erscheint das Objekt oder die Kreatur an einem Ort 3,00 Meter von Dir entfernt.
Es muss Platz für die Kreatur oder das Objekt sein und sie müssen auf festen Boden stehen bzw. liegen können.
Passt das Objekt in Deine Hand (siehe xref:../../rules/core/core_rules_charactercreation.adoc#ref_core_characters_charactercreation_sizecategories[Größenkategorien]), kannst Du entscheiden, dass das Objekt in Deiner Hand erscheint.
Dieser Zauber ist Teleportations-Effekt.
