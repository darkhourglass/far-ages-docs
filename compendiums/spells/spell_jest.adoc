= Narretei

*Arkanes Geheimnis:* Nein  +
*POT:* 4 +
*Rettungswurf:* Nein/Ja +
*Komponenten:* Formeln, Gesten +
*Fokus:* Illusion, Geist +
*Vorbereitung:* 2 +
*Reichweite:* Selbst/Berührung +
*Anzahl der Ziele:* 1 Kreatur/1 Gegenstand +
*Dauer:* 10 Kampfphasen +
*Effekt:*
Mit diesem Zauberspruch verzauberst Du eine Kreatur oder einen Gegenstand so, dass Betrachter des Ziels denken, sie sähen eine Illusion.
Dies wird meistens dadurch erzeugt, dass der Betreffende das Ziel etwas verschwommen bzw. realitätsverrückt sieht oder dieser Zauberspruch dem Ziel eine unwirkliche oder unmögliche, subtile Erscheinung verleiht.
Betrachter müssen sofort eine xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_schools_illusionsm_doupt_illusion[Illusion anzweifeln-Probe] ablegen.
Wenn sie diese bestehen, sind sie davon überzeugt, eine Illusion zu sehen.
Gegenstände von Kreaturen, die mit Narretei verzaubert werden, werden auch verzaubert, wenn sie von der Kreatur am Körper getragen werden.

*Zusätzliche Effekte:* +
+1 MP: Dauer +1 Kampfphase +
