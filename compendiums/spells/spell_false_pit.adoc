= Falsche Grube

*Arkanes Geheimnis:* Nein  +
*POT:* 7 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Illusion +
*Vorbereitung:* 5 +
*Reichweite:* 12,00 Meter +
*Anzahl der Ziele:* bis zu 6,00x6,00 Meter +
*Dauer:* 10 Kampfphasen+
*Effekt:*
Du erschaffst die Illusion einer tiefen Grube oder einer Schlucht auf dem Boden innerhalb der Reichweite, deren Seitenlänge jeweils bis zu 6,00 Meter betragen kann.
Die falsche Grube kann sich innerhalb dieser Grenzen beliebig ausdehnen.
Die Illusion erschafft eine erschreckende Tiefe, so dass Kreaturen, keine Bewegung über das Gebiet ausführen oder versuchen, eine Brücke zu bauen.
Sie können allerdings auch nicht wirklich herunterfallen, denken aber sie würden fallen, sollten sie beispielsweise über den Rand der falschen Grube fallen.
Dies kann zu surrealen Szenen führen, wenn eine schreibende Kreatur strampelnd auf dem Boden liegt und denkt, sie würde eine Grube hinunterfallen.

*Zusätzliche Effekte:* +
