= Speer aus Schatten

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Geste +
*Fokus:* Schatten, Körper +
*Vorbereitung:* 4 +
*Reichweite:* - +
*Anzahl der Ziele:* Linie 12,00 Meter +
*Dauer:* Sofort +
*Effekt:* Du beschwörst eine kleine Menge Schattenenergie zwischen Deinen Handflächen.
Mit der xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] schießt ein speerförmiger Strahl aus schwarzer Energie hervor und durchbohrt alle Ziele im Wirkungsbereich.

Jede Kreatur erhält einen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagerolls_spells[automatischen Magie-Treffer] mit einem Schadenbonus von 6W6.
Jede Kreatur muss einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_KO[KO-Rettungswurf] gegen Deine xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] ablegen.
Besteht eine Kreatur diese Probe, erhält sie nur halbierten Schaden (abgerundet, minimal 1). +
*Zusätzliche Effekte:* +
+5 MP, +1 POT: Anzahl der Ziele Linie +3,00 Meter +
+5 MP: Schadenbonus +1W6 +
