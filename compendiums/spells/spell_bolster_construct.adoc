= Konstrukt verstärken

*Arkanes Geheimnis:* Nein +
*POT:* 7 +
*Rettungswurf:* Ja +
*Komponenten:* Formel, Gesten, Edelsteine im Wert von 1000 Silbermünzen +
*Fokus:* Metall +
*Vorbereitung:* 5 +
*Anzahl der Erfolge:* (1 + Ziel-Machtstufe) +
*Reichweite:* 15,00 Meter +
*Anzahl der Ziele:* 1 link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_construct.adoc[Konstrukt] +
*Dauer:* 5 Kampfphasen +
*Effekt:* Für die Dauer des Zauberspruches kannst Du ein Konstrukt mit einem Bonus verzaubern.
Mit der xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] musst Du einen der folgenden Effekte auswählen:

* +6 WID +
* +3 Rüstungsschutz +
* +1 Würfe zum Erfolg auf Talent-Proben +
* +3 Schadenspunkte pro Schadensprobe

Um einen anderen Effekt zu wirken, musst Du den Zauberspruch wiederholen.
Du kannst ein Konstrukt mehrfach verzaubern, aber immer nur einmal mit dem gewählten Effekt.

Der Zauberspruch wirkt nur auf Konstrukte der Machtstufe 5 oder weniger.
Für Konstrukte höherer Machtstufen musst Du zusätzliche Effekte einsetzen. +
*Zusätzliche Effekte:* +
+1 POT: maximale Machtstufe +1 (mehrfach anwendbar) +
+5 MP: Dauer +1 Kampfphase +
+10 MP, +2 POT: wähle einen Effekt mehr zu Verzauberung (mehrfach anwendbar)
