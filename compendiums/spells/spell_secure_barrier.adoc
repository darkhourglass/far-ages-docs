= Sichere Barriere (Element)

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Aether, Element+
*Vorbereitung:* 3 +
*Reichweite:* 12,00 Meter +
*Anzahl der Ziele:* eine Öffnung 3,00x3,00 Meter +
*Dauer:* 1 Stunde +
*Effekt:* +
Als Ziel für diesen Zauber gilt jede natürlich wie gebaute Öffnung, die zwei Bereiche z.B. Räume abgrenzt, beispielsweise ein Tür- oder Fensteröffnung rahmen, ein Höhlen- oder Tunneleingang, solange die maximale Größe nicht überschritten wird.
Bei erfolgreicher xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_rules_spellcasting_roll[Spruchzauberei-Probe] entsteht eine aetherische Barriere, die das jeweilige *Element* nicht mehr hindurchlässt.
Grundsätzlich können Kreaturen und Gegenstände die Barriere normal passieren - im Ermessen des SLs.
Wurde als Element z.B. *Feuer* gewählt, so könnte ein lodernder Brandherd die Barriere nicht überwinden - die Flammen würden auf der einen Seite der Barriere bleiben.
Allerdings kann der SL entscheiden, ob er einen brennenden Pfeil hindurchlässt.
Als Daumenregel kann man anwenden, dass ein magischer Effekt, dessen POT größer als die POT der Barriere ist, diese überwinden kann.
Dasselbe gilt für Kreaturen, die eine Machtstufe besitzen und diese über der POT der Barriere liegt.
Das Element *Luft* verhindert, dass schädliche Stoffe, wie Giftgase die Barriere überwinden, ebenso schützt die Barriere vor heftigen Stürmen.
Eine Erstickungsgefahr drohnt nicht.
