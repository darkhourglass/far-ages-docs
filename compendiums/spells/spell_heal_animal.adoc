= Heile Tier

*Arkanes Geheimnis:* Nein +
*POT:* 7 +
*Rettungswurf:* Nein +
*Komponenten:* Formel, Geste, Zutat +
*Fokus:* Körper, Erde, Wasser +
*Vorbereitung:* 2 Minuten (Ritual) +
*Anzahl der Erfolge:* 7 +
*Reichweite:* Berührung +
*Anzahl der Ziele:* 1 link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebendes] link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_animal.adoc[Tier] +
*Dauer:* Sofort +
*Effekt:* Die heilende Wirkung der Erde sammelt sich in Deinen Händen und ein schwaches, warmes Licht glüht in ihnen.
Berührst Du ein Tier, schließen sich dessen Wunden wie von Geisterhand.
Als Zutat brauchst Du eine kleine Menge frischen Schlamm.

Du darfst bei erfolgreicher xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] darfst Du einen der folgenden Effekte auswählen:

* Das Tier xref:../../rules/core/core_rules_d10_system.adoc#ref_base_rules_pools_regeneration[regeneriert] sofort 1W10+1 xref:../../rules/core/core_rules_d10_system.adoc#ref_base_rules_pools_tp[TP].
* Das Tier heilt sofort eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds[Verletzung].
* Eine xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases[Krankheit] wird geheilt.
Dazu muss die Anzahl der Erfolge aus Deiner Spruchzauberei-Probe gleicher oder höher der xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases_strengh[Stärke der Krankheit] sein.
* Ein xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons[Gift] wird aus dem Körper des Tiers entfernt.
Dazu muss die Anzahl der Erfolge aus Deiner Spruchzauberei-Probe gleich oder höher der xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_strengh[Giftstärke] sein.

Das Tier darf einen xref:../../rules/core/core_rules_magic_base.adoc#ref_magic_rules_spellcasting_spellspecifics_save[Magie-Rettungswurf] ablegen, falls es nicht von diesem Zauberspruch betroffen sein möchte.

*Zusätzliche Effekte:* +
+ 3 POT: Du darfst zwei Effekte gleichzeitig einsetzen, auch den Gleichen mehrfach (kumulativ anwendbar) +
