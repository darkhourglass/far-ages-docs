= Camouflage

*Arkanes Geheimnis:* Nein +
*POT:* 5 +
*Rettungswurf:* Nein/Ja +
*Komponenten:* Formeln, Gesten +
*Fokus:* Geist, Schatten +
*Vorbereitung:* 4 +
*Reichweite:* Selbst/Berührung +
*Anzahl der Ziele:* 1 Kreatur +
*Dauer:* 5 Kampfphasen +
*Effekt:* +
Dieser Zauberspruch lässt die Zielkreatur mit ihrer Umgebung verschmelzen, so dass sie leicht unentdeckt bleiben kann.
Sie erhält einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_situationalmodifiers_bonus[Bonus] von +5 auf die folgenden Proben:
* xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_hide[Verstecken]
* xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_sneak[Schleichen]
für die Dauer des Zauberspruches.
*Zusätzliche Effekte:* +
+1 MP: Dauer +1 Kampfphase +
