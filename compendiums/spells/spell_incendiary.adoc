= Brandstifter

*Arkanes Geheimnis:* Nein +
*POT:* 5 +
*Rettungswurf:* Nein +
*Komponenten:* Geste +
*Fokus:* Feuer +
*Vorbereitung:* 2 +
*Anzahl der Erfolge:* 3 +
*Reichweite:* 9,00 Meter +
*Anzahl der Ziele:* 1,50 x 1,50 Meter +
*Dauer:* Sofort +
*Effekt:* Du schnipst mit Deinem Finger und mit erfolgreicher Spruchzauberei-Probe beginnt eine Fläche mit 1,50 x 1,50 Metern Maß zu brennen.
Das Feuer gilt als natürliches Feuer und brennt so lange, wie die Beschaffenheit der Fläche es zulässt.
Wird eine Fläche entzündet, deren Material üblicherweise nicht brennt (zum Beispiel Stein), brennt das Feuer bis zum Ende der aktuellen Kampfphase.
+
*Zusätzliche Effekte:* +
+5 MP: weitere Fläche 1,50 x 1,50 Meter
+
