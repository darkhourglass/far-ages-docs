= Zap!

*Arkanes Geheimnis:* Nein  +
*POT:* 9 +
*Rettungswurf:* Ja +
*Komponenten:* Formeln, Geste +
*Fokus:* Illusion, Geist +
*Vorbereitung:* 3 +
*Reichweite:* 9,00 Meter +
*Anzahl der Ziele:* 1 Kreatur +
*Dauer:* Sofort +
*Effekt:*
Du erschafft die Illusion, eines mächtigen Angriffszaubers, den Du gegen Deine Gegner schleuderst.
Dies könnte ein Blitzschlag, Feuerregen oder Vergleichbares sein.
Wichtig ist, dass zur xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_rules_spellcasting_roll[Spruchzauberei-Probe] das Wort ZAP gerufen wird.
Die Ziel-Kreatur (oder Kreaturen bei einem zusätzlichen Effekt) dürfen einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_magic[Magie-Rettungswurf] gegen Deine Spruchzauberei-Probe ablegen.
Bei einem Misserfolg erhalten sie einen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_hits_automatic_hit[automatischen Treffer] mit 4W6+4 xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetype_magical_illusionary[illusionären] Schaden.
Bei einem Erfolg bleibt die Kreatur verschont.
Umstehende Kreaturen dürfen dann eine xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_schools_illusionsm_doupt_illusion[Illusion anzweifel]-Probe würfeln, um zu erkennen, dass Dein Zauber eine Illusion war.
Sollte eine diese Kreaturen auch Ziel des Zaubers sein, erleidet sie auch keinen Schaden.

*Zusätzliche Effekte:* +
+2 MP: Reichweite +3,00 Meter +
+1 MP: Dauer +1 Kampfphase +
+ +5 MP: Ziele: +1 Kreatur
+ 2POT, +2 MP: +1W6+1 Schaden
