= Zorn der Natur

*Arkanes Geheimnis:* Nein +
*POT:* 7 +
*Rettungswurf:* Ja +
*Komponenten:* Formel, Geste +
*Fokus:* Körper, Wachstum +
*Vorbereitung:* 6 +
*Reichweite:* 24,00 Meter +
*Anzahl der Ziele:* 1 Kreatur +
*Dauer:* Sofort +
*Effekt:* Du fokussierst eine Druckwelle ursprünglicher Energie gegen eine Kreatur innerhalb der Reichweite.

Bei erfolgreicher xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] erhält die Kreatur einen xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_hits_automatic_hit[automatischen Treffer] mit 4W6 xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagepoints[Schadenspunkten].
Dieser Schaden erhöht sich, wenn die Kreatur eine oder mehrere Bedingungen erfüllt:

* +2W6, wenn ihr primärer Kreaturentyp einer der folgenden ist: link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_undead.adoc[Untot], link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_monstrosity.adoc[Ungeheuer], link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_abomination.adoc[Scheusal], link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_demon.adoc[Dämon], link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_construct.adoc[Konstrukt]
* +1W10 pro xref:../../rules/advanced/advanced_rules_corruption.adoc#ref_corruptions_rules_corruptionspoints[Korruptionspunkt]

*Zusätzliche Effekte:* +
+2 MP: Reichweite +6,00 Meter +
+10 MP, + 2 POT: Die xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetypes[Schadensart] kann von Dir zu einer der folgenden geändert werden: xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetype_elemental_fire[Feuer], xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetype_aspectelemental_shock[Schock] oder xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_damage_damagetype_aspectelemental_frost[Frost] +
+5 MP: +1W6 Schaden +
