= Unterstützender Akkord

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Geist +
*Vorbereitung:* 3 +
*Reichweite:* - +
*Anzahl der Ziele:* Radius 12,00 Meter +
*Dauer:* Sofort +
*Effekt:* +
Du benötigst ein Musikinstrument, um diesen Zauber auszusprechen, er gilt allerdings nicht als xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_schools_music_spellsongs[Zauberlied].
Mit erfolgreicher xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_rules_spellcasting_roll[Spruchzauberei-Probe] spielst Du einen Akkord auf Deinem Instrument, der die Moral aller Kreaturn im Wirkungsbereich heben kann.
Die Kreaturen müssen dazu link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebendig] sein, hören können und müssen grundsätzlich in der Lage sein, xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_sp[SP] verlieren zu können.
Treffen diese Voraussetzungen auf eine Kreatur im Wirkungsbereich zu, erhält sie sofort 1W6+1 SP zurück, jedoch nie mehr als ihr Pool zulässt.
*Zusätzliche Effekte:* +
+2 POT, +10 MP: Radius +6,00 Meter
