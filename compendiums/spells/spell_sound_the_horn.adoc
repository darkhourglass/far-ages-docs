= Hornbläser

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Schatten +
*Vorbereitung:* 3 +
*Reichweite:* - +
*Anzahl der Ziele:* Radius 100 Meter +
*Dauer:* Sofort +
*Effekt:*
Du faltest Deine Hände röhrenartig aneinender, so dass sie einem hornartigen Instrument geformt werden.
Mit erfolgreicher xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_rules_spellcasting_roll[Spruchzauberei-Probe] pustest Du in eine Seite deines symbolischen Instruments und damit ertönt ein lauter Ton wie von einem Horn geblasen.
Dieser Ton ist überall im Radius des Zaubers (zentriert auf Dir) zu hören.
*Zusätzliche Effekte:*
+2 POT, +10 MP: Radius +50,00 Meter
