= Erschaffe Wasser

*Arkanes Geheimnis:* Nein +
*POT:* 4 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Wasser +
*Vorbereitung:* 2 +
*Reichweite:* Berührung +
*Anzahl der Ziele:* 1 Gefäß +
*Dauer:* Sofort +
*Effekt:*
Du erschaffst einen Liter genießbares und sauberes Wassers.
Das Wasser erscheint in einem von Dir berührten Gefäß - das Gefäß kann überlaufen.
*Zusätzliche Effekte:* +
+1 POT, +5 MP: +1 Liter mehr Wasser erschaffen +
