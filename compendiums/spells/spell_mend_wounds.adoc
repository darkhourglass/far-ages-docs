= Wundheilung

*Arkanes Geheimnis:* Nein +
*POT:* 5 +
*Rettungswurf:* Nein +
*Komponenten:* Formel, Geste +
*Fokus:* Körper +
*Vorbereitung:* 3 +
*Anzahl der Erfolge:* 4 +
*Reichweite:* Berührung +
*Anzahl der Ziele:* 1 link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebende] Kreatur +
*Dauer:* Sofort +
*Effekt:* Du legst Deine Hände auf eine Wunde der Zielkreatur.
Ein angenehmer, warmer Strom arkaner Energie geht von Dir auf die Zielkreatur über.
Bei erfolgreicher Spruchzauberei-Probe schließt sich sofort eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds[Wunde] der Zielkreatur.
Sie gilt als xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds_curing_wounds[geheilt].

Hat die Kreatur mehr als eine Wunde, musst Du die zusätzlichen Effekte dieses Zauberspruches nutzen oder warten.
Eine Kreatur kann erst nach Ablauf von 24 Stunden wieder Ziel dieses Zauberspruches werden.
*Zusätzliche Effekte:* +
+1 POT, +5 MP: heile 1 weitere Wunde +
