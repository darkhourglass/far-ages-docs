= Zungen

*Arkanes Geheimnis:* Nein +
*POT:* 5 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Geist +
*Vorbereitung:* 3 +
*Reichweite:* Berührung/Selbst +
*Anzahl der Ziele:* 1 Humanoider / Selbst +
*Dauer:* 10 Kampfphasen +
*Effekt:* +
Dieser Zauberspruch lässt das Ziel für seine Dauer zu einem Polyglot werden.
Das Ziel versteht und spricht alle nicht-magihn Sprachen, die andere Humanoide in seiner Hörreihweite sprechen.
Der Zauber kann keine Schrift übersetzen.
*Zusätzliche Effekte:* +
+1 MP: Dauer +1 Kampfphase +
