= Beschwöre Erinnerung

*Arkanes Geheimnis:* Nein +
*POT:* 7 +
*Rettungswurf:* nein/ja +
*Komponenten:* Formeln, Gesten +
*Fokus:* Geist, Schatten +
*Vorbereitung:* 5 +
*Reichweite:* Selbst/Berührung +
*Anzahl der Ziele:* 1 link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebende] Kreatur +
*Dauer:* 5 Kampfphasen +
*Effekt:*
Du beschwörst das illusionäre Abbild einer Erinnerung von Dir oder der berührten Zielkreatur.
Sowohl Du als auch die Zielkreatur müssen sich auf die betroffene Erinnerung konzentrieren.
Die Erinnerung kann eine andere Kreatur, ein Objekt oder ein Teil einer Szenerie sein.
Die beschworene Illusion ist nur so genau, wie die Erinnerung selbst ist.
So könnte es sein, dass Deine Erinnerung an eine bestimmte Person bestimmte Details nicht enthält, z.B. welche Ohrringe sie getragen hat, da Du nicht darauf geachtet hast.
Versuchst Du oder die Zielkreatur sich an bestimmte Details zu erinnern, kann der Sl einen xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_checks_saves_magic[Magie-Rettungswurf] verlangen.
Gelingt dieser nicht, erzeugt der Zauber an der Stelle, wo das Detail erscheinen sollte, nur eine blanke, leicht verwaschene Stelle.
Die Erinnerung bzw. deren Illusion verschwindet nach Ablauf der Dauer des Zauberspruches.
