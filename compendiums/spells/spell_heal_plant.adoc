= Heile Pflanze

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Formel, Geste, Zutat +
*Fokus:* Körper, Wachstum +
*Vorbereitung:* 2 Minuten (Ritual) +
*Anzahl der Erfolge:* 7 +
*Reichweite:* Berührung +
*Anzahl der Ziele:* 1 link:../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebendes] link:../../rules/advanced/creaturetypes/primary/creaturetype_primary_plant.adoc[Pflanze] +
*Dauer:* Sofort +
*Effekt:* Die heilende Wirkung der Erde sammelt sich in Deinen Händen und ein grünliches, sanftes Licht glüht in ihnen.
Ein leicht süßlicher Duft liegt in der Luft.
Als Zutat brauchst Du eine kleine Menge frischen Schlamm.

Du darfst bei erfolgreicher xref:../../rules/core/core_rules_talents_base.adoc#ref_talents_spellcasting[Spruchzauberei-Probe] darfst Du einen der folgenden Effekte auswählen:

* Das Tier xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_regeneration[regeneriert] sofort 1W10+1 xref:../../rules/core/core_rules_2d10_system.adoc#ref_core_2d10_pools_tp[TP].
* Das Tier heilt sofort eine xref:../../rules/core/core_rules_battlesystem.adoc#ref_battle_wounds[Verletzung].
* Eine xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases[Krankheit] wird geheilt.
Dazu muss die Anzahl der Erfolge aus Deiner Spruchzauberei-Probe gleich oder höher der xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_diseases_strengh[Stärke der Krankheit] sein.
* Ein xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons[Gift] wird aus dem Körper des Tiers entfernt.
Dazu muss die Anzahl der Erfolge aus Deiner Spruchzauberei-Probe gleich oder höher der xref:../../rules/core/core_rules_adventures.adoc#ref_core_adventures_hazards_poisons_strengh[Giftstärke] sein.

Die Pflanze darf einen xref:../../rules/core/core_rules_magic_base.adoc#ref_magic_rules_spellcasting_spellspecifics_save[Magie-Rettungswurf] ablegen, falls es nicht von diesem Zauberspruch betroffen sein möchte.

Du kannst diesen Zauberspruch auch auf eine Pflanze wirken, die keine Kreatur ist.
In diesem Fall tritt entfernst Du alle negativen Effekte, unter die Pflanze aktuell leidet, zum Beispiel Schädlings- oder Pilzbefall, Krankheiten oder Austrocknung.
Eine abgestorbene Pflanze, sofern ihr Samen noch lebendig ist, kann neu erblühen.

*Zusätzliche Effekte:* +
+ 3 POT: Du darfst zwei Effekte gleichzeitig einsetzen, auch den Gleichen mehrfach (kumulativ anwendbar) +
