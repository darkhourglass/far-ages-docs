= Sichtfenster

*Arkanes Geheimnis:* Nein +
*POT:* 8 +
*Rettungswurf:* Nein +
*Komponenten:* Formeln, Gesten +
*Fokus:* Geist +
*Vorbereitung:* 4 +
*Reichweite:* 6,00 Meter +
*Anzahl der Ziele:* 1 Wand oder hinderniss +
*Dauer:* 5 +
*Effekt:*
DU erzeugst ein Sichtfenster auf einem Hindernis, z.B. einer Wand.
Dieses Sichtfenster ist nur auf Deiner Seite zu sehen und gewährt einen Blick auf die andere Seite des Hindernisses.
Dieser Zauberspruch erzeugt keine Illusion, jedoch können Wesen auf der anderen Seite eine xref:../../rules/core/core_rules_magic_base.adoc#ref_core_magic_schools_illusionsm_doupt_illusion[Illusion anzweifeln] Probe ablegen.
Wenn sie diese bestehen, bemerken sie, dass mit der Wand etwas „nicht stimmt“ und sie haben, das Gefühl beobachtet zu werden.
*Zusätzliche Effekte:* +
+1 MP: Dauer +1 Kampfphase +
