= Blutwein
*Voraussetzung*+
link:../../../rules/core/skills/core_skill_alchemy.adoc[Alchemie] +
xref:../../../rules/core/core_rules_talents_base.adoc#ref_talents_knowledge[Wissen (Okkultes)] 5 +
*Mindestwurf:* 18+
*Menge/Portion:* 1 Liter +
*Beschreibung:*
Blutwein ist ein alchemistisches Gebräu, dass wie der Name suggeriert, Blut und Wein mischt.
xref:../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_vampire.adoc[Vampire] erhalten durch den Verzehr einer Portion Blutwein 1W10 TP zurück.
Alle anderen Kreaturen können diesen Wein auch trinken, jedoch ohne zusätzliche Effekte, außer einem merkwürdigen Nachgeschmack.
