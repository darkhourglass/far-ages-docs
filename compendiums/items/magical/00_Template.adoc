= Name

*Speziell:* Besondere Zutaten, um den Gegenstand zu erschaffen. +
*Machtstufe:* die Machtstufe des Gegenstandes +
*Bindung:* Was ein zukünftiger Benutzer des Gegenstandes opfern muss, um den Gegenstand an sich zu binden.
Ist keine Angabe gemacht, ist keine Bindung nötig. +
*CP:* CP-Kosten, um das Rezept zu lernen. +
*Beschreibung:* Beschreibt, welcher Effekt regeltechnisch auf dem Gegenstand nach diesem Rezept liegt.
