= Zaubertattoo

*Speziell:* magische Tinte (20.000 Silber) +
*Machtstufe:* 4 (außergewöhnlich) +
*Bindung:* 1 TP +
*CP:* 500 CP +
*Beschreibung:* Ein magisches Tattoo, auch Zaubertattoo ist eine seltene und wenig bekannte Technik, um einen magischen Effekt dauerhaft auf der Haut eines link:../../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_living.adoc[lebenden], dass nicht link:../../../../rules/advanced/creaturetypes/secondary/creaturetype_secondary_incorporal.adoc[körperlos] ist, zu verankern.
Diese Disziplin ist verwandt mit der xref:../../../../rules/core/core_rules_magic_base.adoc#ref_core_magic_schools_runes[Runenmagie] und wird von wenigen Eingeweihten verwendet.
Ein einziges Tattoo kann einen Zauber mit POT 7 oder weniger festschreiben.
Der Zauber muss unter der Angabe Dauer eine längere Dauer als "sofort" besitzen.
Wird das Tattoo erfolgreich tätoowiert, wirkt der Effekt des Zaubers dauerhaft mit der tätoowierten Kreatur als Mittelpunkt.
Eine Kreatur kann nie mehr als 1 Zaubertattoo gleichzeitig besitzt.
Die Probe zum Tattoowieren wird das xref:../../../../rules/core/core_rules_magic_items.adoc#ref_magic_items_createmagicalitem_talent[Talent] gewürfelt, allerdings benötigt der ausführende Hersteller auch xref:../../../../rules/core/core_rules_talents_base.adoc#ref_talents_knowledge[Wissen] (Arkanes) und xref:../../../../rules/core/core_rules_talents_base.adoc#ref_talents_craft[Handwerk] (Tätowieren) auf mindestens Stufe 5.
[NOTE]
Diese Technik muss erst entdeckt werden, bevor sie von Charakteren genutzt werden kann.
