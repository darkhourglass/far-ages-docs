= Nebelverteiler

*Materialkosten:* 30.000 +
*Konstruktionszeit:* 3 Tage +
*Zaubersprüche:* link:../../../spells/spell_fog.adoc[Nebel] +
*Mindestwurf:* 16 +
*Montage:* - +
*MP-Kosten:* siehe Beschreibung +
*Machtstufe:* 0 +
*Beschreibung:* Dieser Zusatz besteht aus einer semi-transparenten Kammer, in der eine neblige Masse wabert.
Weiterhin benötigt dieser Zusatz einige Rohre, die am Körper des Golems von der Kammer aus verlaufen.
Die Rohre enden in trichterförmigen Aufsätzen, die durch ein engmaschiges Netz abgedeckt sind.

Mit einer xref:../../../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_additionalactions_bonusactions[Bonus-Aktion] kann der Golem mit ein Einsatz der MP-Kosten (siehe auch unten stehende Tabelle) den Effekt des Zauberspruches link:../../../spells/spell_fog.adoc[Nebel] in einem Radius von 12,00 Metern um sich herum erzeugen.

Je nach MP-Kosten bestimmt der Golem die Intensität des Nebels:

|===
|MP-Kosten |Nebeleffekt

|5
|xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_coverage[geringe Deckung]

|10
|xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_coverage[mittlere Deckung]

|20
|xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_coverage[starke Deckung]

|40
|xref:../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_melee_modifiers_coverage[totale Deckung]
|===

Der Golem kann den Nebel durch eine xref:../../../../rules/core/core_rules_battlesystem.adoc#ref_core_battle_freeactions[freie Aktion] in seiner Kampfphase beenden.
