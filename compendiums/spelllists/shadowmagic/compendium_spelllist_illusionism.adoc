= Illusionismus
[NOTE]
Viele Illusionen und Zauber dieser Liste beschreiben eine Verzerrung von der gespielten Realität ohne konkrete Regeln vorzugeben, wie mit dieser umzugehen ist.
Dies ist bewusst so gestaltet, damit die Spielgruppen ihre Kreativität ausleben können.
Geht respektvoll mit dieser Macht um.
