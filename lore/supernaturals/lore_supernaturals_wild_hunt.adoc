= Die Wilde Jagd

Die Wilde Jagd ist kein Einzelwesen, sondern ein armeeähnlicher Zusammenschluss von übernatürlichen Wesen.

=== Forderungen der Wilden Jagd

Die Wilde Jagd fordert von ihren Dienern beispielsweise:

* das Töten einer besonders gefährlichen Kreaturen, üblicherweise mit der Überbringung einer Trophäe
* den Sieg über einen anderen Diener der Wilden Jagd in einem Duell
* das Beseitigen von unehrenhaften Jägern wie z.B. Wilderern
